PART 0시작 전

입문 과정(첫 설정 12단계)을 끝낸 사람이 회사에서 실제로 쓰는 앱을 보고, 같은 앱의 작은 판을 말로 만들고 말로 고쳐 보는 30분 체험입니다. 각 단계 오른쪽 위 완료를 체크하면 위쪽 막대에 진행률이 표시됩니다.

오늘의 주제주제는 출퇴근이 아니라 「사내 앱을 말로 만든다」입니다. 출퇴근 앱은 예시일 뿐입니다. 끝나면 「우리 팀에서 매일 손으로 하는 일 중 앱이 될 만한 것」을 한 줄 적습니다.
끝나면 이렇게 됩니다
  • 휴대폰으로 완성본 앱에서 출근을 찍어 봤다.
  • 내 노트북에 출퇴근.html 파일 하나를 글 한 장으로 만들었다.
  • 코드를 보지 않고 말로만 기능 세 가지를 고쳤다.

오늘 만드는 것과 완성본은 무엇이 다른가요?

완성본 (보기만)미니 앱 (내가 만든다)
어디서 여나휴대폰 · 인터넷 주소내 노트북 · 파일 더블클릭
로그인구글 로그인 + 명단 확인없음
기록구글 시트화면 표 + CSV 내려받기
알림09:35 메일없음

완성본을 똑같이 만들려면 계정 설정이 여러 개 필요해서 30분에 끝나지 않습니다. 그래서 오늘은 핵심 기능 세 가지(출근 버튼 → 회사 반경 판정 → 기록)만 가진 한 파일짜리 앱을 만듭니다.

① 보기·만들기 1~7단계 · 15분

PART 1완성본 써 보기 (1~3단계)

회사에서 Claude Code 로 만든 출퇴근 앱입니다. 화면·서버·기록·메일이 모두 말로 요청해서 만들어졌습니다.

1

휴대폰으로 열기

방법

진행자가 띄운 QR 을 찍거나 아래 주소를 휴대폰 Chrome(아이폰은 Safari)에서 엽니다.

https://jichang999-dotcom.github.io/tes2/commute/index.html
확인

「출퇴근」 제목과 [Google 계정으로 로그인] 버튼이 보인다.

주의카카오톡 안에서 링크를 누르면 카카오톡 브라우저로 열려 로그인이 막힐 수 있습니다. 오른쪽 위 메뉴에서 다른 브라우저로 열기를 고릅니다.
2

구글 로그인

방법

[Google 계정으로 로그인] → 진행자에게 알려 준 구글 계정을 고릅니다.

확인

[출근] [퇴근] 버튼이 있는 화면으로 바뀐다.

막히면접속이 막혔다는 안내가 뜨면 그 계정이 명단에 없는 것입니다. 진행자에게 이메일을 알려 주고, 기다리는 동안 옆 사람 화면으로 보고 PART 2 로 넘어갑니다.
3

출근 찍기

방법

[출근] → 위치 권한을 물으면 허용.

확인

회사에서 몇 m 인지가 나오고, 화면 아래 기록 표에 오늘 줄이 생긴다.

알아 두기회사 반경은 100m 입니다. 건물 안에서는 GPS 가 흔들려서 「거리 − 오차」가 100m 안이면 통과로 칩니다. 이 규칙도 사람이 말로 정한 것입니다(PART 4).

PART 2미니 앱 만들기 (4~7단계)

이제 같은 앱의 작은 판을 내 노트북에 만듭니다. 글을 직접 치지 않고 카드를 복사해 붙여넣습니다. 모두 같은 글로 시작해야 진행자가 한 화면으로 안내할 수 있습니다.

4

체험 폴더 만들고 열기

방법
  1. 바탕화면에 영어 · 공백 없는 이름으로 새 폴더를 만듭니다. 예: app_trial
  2. VS Code(또는 Cursor) → [파일] > [폴더 열기] → 방금 만든 폴더
  3. 터미널을 열고 claude 입력 → Enter (폴더 신뢰를 물으면 Yes, I trust this folder)
확인

Claude Code 입력창이 뜨고, 위쪽에 방금 만든 폴더 경로가 보인다.

기억 나지 않으면입문 가이드 5단계(폴더 열기) · 6단계(터미널)와 같습니다.
5

만들기 카드 붙여넣기

방법

[복사] → Claude Code 입력창 클릭 → Ctrl + V → Enter. 1~3분 걸립니다.

이 폴더에 출퇴근.html 파일 하나를 만들어 줘. 다른 파일이나 설치는 필요 없게. - 큰 [출근] [퇴근] 버튼 - 누르면 내 위치를 받아서 회사 좌표(37.47381, 126.99494)에서 몇 m 인지 보여 줘 - 100m 안이면 기록, 밖이면 "반경 밖" 안내 - 위치가 안 잡힐 때를 위해 [테스트 모드] 스위치: 켜면 회사 좌표에 있는 것으로 친다 - 기록은 아래 표(날짜 · 출근 · 퇴근 · 거리)에 쌓이고 새로고침해도 남게 - [CSV 내려받기] 버튼, 연습용 [기록 지우기] 버튼 - 맨 위 한 줄에 지금 설정(반경, 기준 시각 09:30)을 보여 줘 끝나면 파일을 여는 방법을 한 줄로 알려 줘.

파일을 만들어도 되는지 물으면 Yes 를 고릅니다.

확인

마지막에 「여는 방법: … 더블클릭 …」 같은 한 줄이 나오고, 왼쪽 탐색기에 출퇴근.html 이 생긴다.

5분 규칙5분이 지나도 파일이 안 생기면 고치려 하지 말고 정답 파일로 갈아탑니다 — 받은 정답_출퇴근.html 을 체험 폴더에 넣고 이름을 출퇴근.html 로 바꾼 뒤 6단계로. 고치기 체험은 정답 파일로도 똑같이 됩니다.
6

파일 열어 보기

방법

탐색기(윈도우 폴더 창)에서 체험 폴더의 출퇴근.html 을 더블클릭 → Chrome 이나 Edge 로 열립니다.

확인

맨 위 설정 줄(반경 100m · 기준 시각 09:30) · [출근] [퇴근] · [테스트 모드] · 표 · [CSV 내려받기] [기록 지우기] 가 보인다.

7

출근 찍어 보기

방법

[출근] → 위치 권한을 물으면 허용. 아무 반응이 없거나 「반경 밖」이면 [테스트 모드] 를 켜고 다시 [출근].

확인

표에 오늘 날짜 줄이 생긴다. 새로고침(F5)해도 남아 있다.

왜 테스트 모드가 있나요?노트북에는 GPS 가 없어 와이파이로 위치를 잡습니다. 회사 노트북은 위치 서비스가 꺼져 있는 경우가 많아, 그때도 체험이 멈추지 않도록 카드에 넣어 두었습니다. 실제 위치 판정은 PART 1 휴대폰에서 이미 해 봤습니다.
② 말로 고치기 8~10단계 · 10분

PART 3말로 고치기 (8~10단계)

여기부터는 카드를 복사하지 않습니다. 미션에는 원하는 것만 적혀 있습니다. 자기 말로 Claude Code 에 시키고, 끝나면 브라우저에서 F5(새로고침)로 확인합니다.

요령코드를 몰라도 됩니다. 「무엇을 원하는지」나 「무엇이 이상한지」를 평소 말로 적으면 됩니다. 예시 문장은 막혔을 때만 보세요.
8

미션 1 — 회사 반경을 100m 에서 300m 로

원하는 것

회사 반경을 넓히고 싶다.

예시 문장 보기
회사 반경을 100m에서 300m로 넓혀 줘
확인

새로고침한 화면 맨 위 설정 줄에 300m.

9

미션 2 — 퇴근하면 일한 시간 보이게

원하는 것

퇴근을 누르면 그날 일한 시간이 표에 보이면 좋겠다.

예시 문장 보기
퇴근을 누르면 그날 일한 시간(몇 시간 몇 분)이 기록 표에 보이게 해 줘
확인

새로고침 → [퇴근] → 표에 「몇 시간 몇 분」. 7단계에서 찍은 출근 시각부터 지금까지 시간이 나옵니다. 기록을 지웠다면 [출근] 부터.

10

미션 3 — 마음에 안 드는 곳 하나 고치기

원하는 것

화면을 보고 마음에 안 드는 곳 하나를 증상으로 설명합니다.

이렇게 말하면 된다
버튼이 너무 작아요. 휴대폰에서도 누르기 쉽게 크게 해 줘
퇴근 버튼 색을 파란색으로 바꿔 줘
표에 요일도 같이 보여 줘
확인

내가 원한 대로 바뀌었으면 통과. 판정은 본인이 합니다.

③ 더 알아보기 각자 읽기

PART 4완성본은 어떻게 생겼나

방금 만든 미니 앱에 서버 · 로그인 · 메일을 붙인 것이 완성본입니다. 이것도 전부 말로 요청해서 만들었습니다.

조각하는 일미니 앱에는
화면 (인터넷 주소)구글 로그인 · 위치 받기 · 거리 표시있다 (내 노트북 파일)
서버 (구글 Apps Script)로그인한 사람이 명단에 있는지 확인 · 거리를 다시 계산 · 기록없다
기록 (구글 시트)날짜 · 출근 · 퇴근 · 거리 쌓기브라우저 저장 + CSV
알림 (메일)09:35 에 한 번, 본인과 팀장에게없다

만들며 부딪힌 것 세 가지 — 셋 다 말로 설명해서 고쳤다

무슨 일이 있었나어떻게 말했나결과
사무실 안인데 「반경 밖」「건물 안에서는 GPS 오차가 커서 자꾸 밖이라고 나와」「거리 − 오차 ≤ 100m」 로 봐주기
정시에 왔는데 지각으로 찍힘「09:12 에 왔는데 지각이래」시트가 시각을 날짜로 바꿔 버리는 문제를 찾아 고침
위치가 조용히 안 받아짐「버튼을 눌러도 위치를 안 물어봐」화면과 서버를 둘로 나눔 (한 덩어리로는 위치 권한이 막힌다)
핵심코드는 Claude Code 가 썼고, 반경 · 기준 시각 · 알림 받을 사람 같은 규칙은 사람이 정했습니다. 사람이 할 일은 「무엇을 원하는지」와 「무엇이 이상한지」를 말하는 것입니다.

PART 5우리 팀 앱 떠올리기

매일 손으로 하는 일 중에 「버튼 → 판정 → 기록」 모양인 것은 오늘 만든 것과 같은 방식으로 앱이 됩니다.

손으로 하던 일버튼판정기록
회의실 예약[예약]그 시간이 비었나예약표
비품 신청[신청]재고가 있나신청 목록
방문객 기록[입실] [퇴실]—방문 기록표
교재 재고 확인[입고] [출고]부족하면 표시재고표

떠오르지 않으면 Claude Code 에 물어봐도 됩니다.

PART 6막혔을 때

먼저만들기(4~7단계)에서 5분 넘게 막히면 정답 파일로 갈아타고 미션으로 넘어갑니다. 받은 정답_출퇴근.html 을 체험 폴더에 넣고 이름을 출퇴근.html 로 바꿉니다.
증상원인해결
휴대폰에서 로그인하면 접속이 막혔다는 안내그 계정이 명단에 없다진행자에게 이메일을 알려 준다
휴대폰 로그인 창이 하얗게 멈춘다카카오톡 등 앱 안 브라우저Chrome · Safari 로 다시 연다
claude 가 안 켜진다입문 과정이 덜 끝났다입문 가이드 「막혔을 때」
