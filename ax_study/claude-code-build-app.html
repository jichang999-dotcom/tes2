PART 0시작 전

입문 과정(첫 설정 12단계)을 끝낸 사람이 회사에서 실제로 쓰는 앱을 보고, 같은 앱의 작은 판을 말로 만들고 말로 고치고, 구글 시트에 기록이 쌓이게 연결해 보는 45분 체험입니다. 각 단계 오른쪽 위 완료를 체크하면 위쪽 막대에 진행률이 표시됩니다.

오늘의 주제주제는 출퇴근이 아니라 「사내 앱을 말로 만든다」입니다. 출퇴근 앱은 예시일 뿐입니다.
끝나면 이렇게 됩니다
  • 휴대폰으로 완성본 앱에서 출근을 찍어 봤다.
  • 내 노트북에 출퇴근.html 파일 하나를 글 한 장으로 만들었다.
  • 코드를 보지 않고 말로만 기능 두 가지를 고쳤다.
  • 내 구글 시트를 저장소(DB)로 만들고, 앱에서 누른 출근이 시트에 한 줄씩 쌓이게 연결했다.

오늘 만드는 것과 완성본은 무엇이 다른가요?

PART 1완성본 써 보기 (1~3단계)

회사에서 Claude Code 로 만든 출퇴근 앱입니다. 화면·서버·기록·메일이 모두 말로 요청해서 만들어졌습니다.

1

휴대폰으로 열기

방법

아래 QR 을 휴대폰 카메라로 찍거나 주소를 휴대폰 Chrome(아이폰은 Safari)에서 엽니다.

https://jichang999-dotcom.github.io/tes2/commute/index.html
확인

「출퇴근」 제목과 [Google 계정으로 로그인] 버튼이 보인다.

주의카카오톡 안에서 링크를 누르면 카카오톡 브라우저로 열려 로그인이 막힐 수 있습니다. 오른쪽 위 메뉴에서 다른 브라우저로 열기를 고릅니다.
2

구글 로그인

방법

[Google 계정으로 로그인] → 진행자에게 알려 준 구글 계정을 고릅니다.

확인

[출근] [퇴근] 버튼이 있는 화면으로 바뀐다.

막히면접속이 막혔다는 안내가 뜨면 그 계정이 명단에 없는 것입니다. 진행자에게 이메일을 알려 주고, 기다리는 동안 옆 사람 화면으로 보고 PART 2 로 넘어갑니다.
3

출근 찍기

방법

[출근] → 위치 권한을 물으면 허용.

확인

회사에서 몇 m 인지가 나오고, 화면 아래 기록 표에 오늘 줄이 생긴다.

알아 두기회사 반경은 100m 입니다. 건물 안에서는 GPS 가 흔들려서 「거리 − 오차」가 100m 안이면 통과로 칩니다. 이 규칙도 사람이 말로 정한 것입니다.

PART 2미니 앱 만들기 (4~7단계)

이제 같은 앱의 작은 판을 내 노트북에 만듭니다. 글을 직접 치지 않고 카드를 복사해 붙여넣습니다. 모두 같은 글로 시작해야 진행자가 한 화면으로 안내할 수 있습니다.

4

작업 폴더에서 Claude Code 켜기

방법
  1. 입문 과정에서 만든 작업 폴더(예: claude_work)를 VS Code(또는 Cursor)로 엽니다. 이미 열려 있으면 그대로.
  2. 터미널에서 claude 입력 → Enter

새 폴더는 만들지 않습니다. 다음 단계의 카드가 작업 폴더 안에 app_trial 폴더를 만들어 줍니다.

확인

Claude Code 입력창이 뜨고, 위쪽에 작업 폴더 경로가 보인다.

기억 나지 않으면입문 가이드 5단계(폴더 열기) · 6단계(터미널)와 같습니다.
5

만들기 카드 붙여넣기

방법

[복사] → Claude Code 입력창 클릭 → Ctrl + V → Enter. 1~3분 걸립니다.

지금 작업 폴더 안에 app_trial 폴더를 만들고, 그 안에 출퇴근.html 파일 하나를 만들어 줘. 다른 설치는 필요 없게. - 큰 [출근] [퇴근] 버튼 - 누르면 내 위치를 받아서 회사 좌표(37.47381, 126.99494)에서 몇 m 인지 보여 줘 - 100m 안이면 기록, 밖이면 "반경 밖" 안내 - 위치가 안 잡힐 때를 위해 [테스트 모드] 스위치: 켜면 회사 좌표에 있는 것으로 친다 - 기록은 아래 표(날짜 · 출근 · 퇴근 · 거리)에 쌓이고 새로고침해도 남게 - [CSV 내려받기] 버튼, 연습용 [기록 지우기] 버튼 - 맨 위 한 줄에 지금 설정(반경, 기준 시각 09:30)을 보여 줘 - 같은 app_trial 폴더에 CLAUDE.md 도 만들어 줘: 이 앱이 무엇인지, 지금 설정(회사 좌표 · 반경 · 기준 시각), 기록이 어디에 저장되는지를 짧게 적고, 출퇴근.html 을 고치면 CLAUDE.md 의 설정도 같이 고치라고 적어 줘. 작업 폴더에 원래 있던 CLAUDE.md 는 건드리지 않는다 끝나면 파일을 여는 방법을 한 줄로 알려 줘.

파일을 만들어도 되는지 물으면 Yes 를 고릅니다.

확인

마지막에 「여는 방법: … 더블클릭 …」 같은 한 줄이 나오고, 왼쪽 탐색기에 app_trial 폴더와 그 안의 출퇴근.html · CLAUDE.md 가 생긴다.

CLAUDE.md 는 왜 만드나요?이 앱의 설명서입니다. 앱이 무엇인지, 지금 설정(반경 · 기준 시각)이 무엇인지 적혀 있어서, 다음에 Claude Code 가 이 폴더를 고칠 때 먼저 읽고 시작합니다. 미션으로 반경을 바꾸면 설명서의 반경도 같이 바뀝니다. 입문에서 만든 작업 폴더의 CLAUDE.md 는 그대로 둡니다.
5분 규칙5분이 지나도 파일이 안 생기면 고치려 하지 말고 정답 파일로 갈아탑니다 — 작업 폴더 안에 app_trial 폴더를 만들고(없으면), 받은 정답_출퇴근.html 을 넣어 이름을 출퇴근.html 로 바꾼 뒤 6단계로. 고치기 체험은 정답 파일로도 똑같이 됩니다.
정답 파일로 갈아탔다면 — 설명서 카드

정답 파일에는 앱 설명서(CLAUDE.md)가 없습니다. 이 카드를 붙여넣으면 만들어 줍니다. 없어도 미션은 됩니다.

app_trial 의 출퇴근.html 을 읽고 같은 폴더에 CLAUDE.md 를 만들어 줘: 이 앱이 무엇인지, 지금 설정(회사 좌표 · 반경 · 기준 시각), 기록이 어디에 저장되는지를 짧게 적고, 출퇴근.html 을 고치면 CLAUDE.md 의 설정도 같이 고치라고 적어 줘. 출퇴근.html 은 고치지 않는다. 작업 폴더에 원래 있던 CLAUDE.md 는 건드리지 않는다

파일 열어 보기

방법

탐색기(윈도우 폴더 창)에서 작업 폴더 → app_trial → 출퇴근.html 을 더블클릭 → Chrome 이나 Edge 로 열립니다.

확인

맨 위 설정 줄(반경 100m · 기준 시각 09:30) · [출근] [퇴근] · [테스트 모드] · 표 · [CSV 내려받기] [기록 지우기] 가 보인다.

7

출근 찍어 보기

방법

[출근] → 위치 권한을 물으면 허용. 아무 반응이 없거나 「반경 밖」이면 [테스트 모드] 를 켜고 다시 [출근].

확인

표에 오늘 날짜 줄이 생긴다. 새로고침(F5)해도 남아 있다.

왜 테스트 모드가 있나요?노트북에는 GPS 가 없어 와이파이로 위치를 잡습니다. 회사 노트북은 위치 서비스가 꺼져 있는 경우가 많아, 그때도 체험이 멈추지 않도록 카드에 넣어 두었습니다. 실제 위치 판정은 PART 1 휴대폰에서 이미 해 봤습니다.
② 말로 고치기 8~10단계 · 12분

PART 3말로 고치기 (8~10단계)

여기부터는 카드를 복사하지 않습니다. 미션에는 원하는 것만 적혀 있습니다. 자기 말로 Claude Code 에 시키고, 끝나면 브라우저에서 F5(새로고침)로 확인합니다.

요령코드를 몰라도 됩니다. 「무엇을 원하는지」나 「무엇이 이상한지」를 평소 말로 적으면 됩니다. 예시 문장은 막혔을 때만 보세요.

원하는 것

회사 반경을 넓히고 싶다.

예시 문장 보기
회사 반경을 100m에서 300m로 넓혀 줘
확인

새로고침한 화면 맨 위 설정 줄에 300m.

9

미션 2 — 퇴근하면 일한 시간 보이게

원하는 것

퇴근을 누르면 그날 일한 시간이 표에 보이면 좋겠다.

예시 문장 보기
퇴근을 누르면 그날 일한 시간(몇 시간 몇 분)이 기록 표에 보이게 해 줘
확인

새로고침 → [퇴근] → 표에 「몇 시간 몇 분」. 7단계에서 찍은 출근 시각부터 지금까지 시간이 나옵니다. 기록을 지웠다면 [출근] 부터.

10

마무리 — 내 앱을 폰 화면으로 보기

방법

고친 앱을 휴대폰 모양 틀 안에 띄워 봅니다. 이것도 카드 [복사] → 붙여넣기 → Enter. 1~2분 걸립니다.

app_trial 폴더 안에 폰미리보기.html 파일 하나를 만들어 줘. 다른 파일이나 설치는 필요 없게. - 화면 가운데에 휴대폰 모양 틀(둥근 모서리, 검은 테두리, 위쪽 카메라 자리)을 그린다. 카메라 자리가 화면 내용을 가리지 않게 - 틀 안에 같은 폴더의 출퇴근.html 을 휴대폰 화면 크기(가로 390, 세로 844)로 띄운다 - 틀 아래에 [새로고침] 버튼: 누르면 틀 안 화면만 다시 불러온다 (iframe 의 src 를 다시 넣는 방식으로. 파일을 더블클릭해서 열어도 되게) - 출퇴근.html 은 고치지 않는다 끝나면 파일을 여는 방법을 한 줄로 알려 줘.

탐색기에서 app_trial → 폰미리보기.html 을 더블클릭합니다. 노트북 화면이 작아 휴대폰 틀이 잘리면 Ctrl + - 로 화면을 줄입니다(Ctrl + 0 이 원래 크기).

확인

휴대폰 모양 틀 안에 내 출퇴근 앱이 보이고, 틀 안에서 [테스트 모드] → [출근] 이 눌린다. 미션으로 고친 것(300m · 일한 시간)도 그대로 보인다.

더 고치고 싶으면이 화면을 켜 둔 채 Claude Code 에 말로 시키고, 틀 아래 [새로고침] 을 누르면 바뀐 모습이 폰 화면으로 보입니다. 막히면 받은 정답_폰미리보기.html 을 app_trial 에 넣고 이름을 폰미리보기.html 로 바꿉니다.
③ 시트를 DB 로 11~14단계 · 15분

PART 4구글 시트를 DB 로 (11~14단계)

지금 기록은 내 브라우저 안에만 있습니다. 브라우저를 바꾸거나 기록을 지우면 사라집니다. 이제 구글 시트를 저장소(DB)로 쓰고, 그 앞에 Apps Script 웹앱을 세워 앱이 기록을 보내게 합니다. 완성본도 같은 구조입니다.

출퇴근.html (화면)서버.gs (Apps Script 웹앱)구글 시트 (DB)
[출근] 을 누르면 기록 한 줄을 보낸다→
웹앱 주소		받아서 시트에 쓴다 · 같은 날짜면 그 줄을 고친다→날짜 · 출근 · 퇴근 · 거리가 쌓인다
누가 무엇을 하나코드(서버.gs · 연결)는 Claude Code 가 씁니다. 사람은 시트 만들기 · 코드 붙여넣기 · 배포 세 가지만 브라우저에서 손으로 합니다.

sheets.new

12

서버 코드 카드 붙여넣기

방법

Claude Code 입력창에 [복사] → Ctrl + V → Enter. 1~2분 걸립니다.

app_trial 폴더에 서버.gs 파일을 만들어 줘. 구글 시트에 붙여 웹앱으로 배포할 Apps Script 코드다. - doPost: 출퇴근.html 이 보낸 기록 한 줄(표에 있는 칸 그대로)을 받아 이 스크립트가 붙은 시트의 첫 탭에 저장한다. 같은 날짜 줄이 있으면 그 줄을 고친다 - doGet: 저장된 기록 전체를 JSON 으로 돌려준다 - 첫 줄이 비어 있으면 머리글을 먼저 쓴다 - 앱은 Content-Type 을 text/plain 으로 보낸다(브라우저의 사전 요청을 피하려고). 받는 쪽은 본문을 JSON 으로 읽는다 - 날짜 · 시각은 시트가 날짜 값으로 바꾸지 않게 글자 그대로 저장한다 출퇴근.html 은 아직 고치지 않는다. app_trial 의 CLAUDE.md 에 서버.gs 가 무엇인지 한 줄 추가해 줘. 끝나면 서버.gs 를 시트에 붙이는 방법을 세 줄로 알려 줘.
확인

app_trial 안에 서버.gs 가 생기고, 마지막에 「시트에 붙이는 방법」 세 줄이 나온다.

5분 규칙서버.gs 가 안 생기면 받은 정답_서버.gs 를 app_trial 에 넣고 이름을 서버.gs 로 바꾼 뒤 13단계로. 14단계 연결 카드는 정답 파일로도 똑같이 됩니다.
13

시트에 붙이고 웹앱으로 배포

방법
  1. 11단계 시트에서 메뉴 [확장 프로그램] → [Apps Script]. 새 탭에 코드 편집기가 열립니다.
  2. 편집기 안의 코드를 전부 지웁니다(Ctrl + A → Delete). VS Code 에서 서버.gs 를 열어 전부 복사해 붙여넣고 저장(Ctrl + S).
  3. 오른쪽 위 [배포] → [새 배포] → 톱니(유형 선택) → [웹 앱]
  4. 실행 계정: 나 · 액세스 권한이 있는 사용자: 모든 사용자 → [배포]
  5. [액세스 승인] → 내 계정 선택. 「Google에서 확인하지 않은 앱」이 뜨면 [고급] → [(안전하지 않음)으로 이동] → [허용]
  6. 「웹 앱 URL」(…/exec 로 끝나는 주소) 옆 [복사]
확인

복사한 주소를 브라우저 새 탭에 붙여넣어 열면 [] 처럼 대괄호로 된 글자가 보인다(아직 기록이 없어서 빈 목록).

주의「확인하지 않은 앱」 경고는 내가 방금 만든 스크립트라서 뜹니다(구글 검토를 안 받았다는 뜻). 다른 사람이 보낸 스크립트라면 허용하지 않습니다. 액세스 권한 목록에 「모든 사용자」가 없으면 회사 계정 정책으로 막힌 것입니다 — 진행자에게 알립니다.
14

앱과 시트 연결

방법
  1. 아래 카드 [복사] → Claude Code 입력창에 붙여넣기. 아직 Enter 를 누르지 않습니다.
  2. Apps Script 탭에서 [배포] → [배포 관리] → 웹 앱 URL [복사]
  3. 입력창 맨 끝 「웹앱 주소:」 뒤에 붙여넣기 → Enter
출퇴근.html 을 구글 시트에 연결해 줘. 웹앱 주소는 맨 아래 줄에 붙였다. - 출근 · 퇴근을 기록할 때 이 주소로도 보낸다. Content-Type 은 text/plain 으로 보낸다(본문은 JSON 글자) - 보내는 칸 이름은 같은 폴더 서버.gs 가 받는 이름과 맞춘다 - 화면의 표와 브라우저 저장은 그대로 둔다. 보내기에 실패하면 화면에 "시트 저장 실패" 를 잠깐 보여 주고 기록은 화면에 남긴다 - 맨 위 설정 줄에 "시트 연결됨" 을 보여 줘 - app_trial 의 CLAUDE.md 에 웹앱 주소와 시트 칸 구성을 적어 줘 웹앱 주소:
확인

브라우저에서 출퇴근.html 을 F5 → 맨 위 설정 줄에 「시트 연결됨」. [테스트 모드] → [출근] 을 누르고 시트 탭을 보면 몇 초 안에 오늘 줄이 생긴다. [퇴근] 을 누르면 같은 줄에 퇴근 시각이 채워진다.

무엇이 달라졌나이제 기록이 내 노트북 밖(구글 시트)에 있습니다. 다른 노트북이나 휴대폰에서 이 앱을 열어도 같은 시트에 쌓입니다 — 여러 사람이 쓰는 사내 앱은 여기서 시작합니다. 대신 웹앱 주소를 아는 사람은 누구나 기록을 쓸 수 있습니다. 실제 사내 앱은 완성본처럼 로그인 · 명단 확인을 붙입니다. 체험이 끝나면 [배포 관리] 에서 이 배포를 보관해 닫아도 됩니다.
