시작 전업무 데이터는 파일 하나에 모여 있지 않습니다

교육 편에서는 받은 CSV 파일 하나로 스킬과 에이전트를 만들었습니다. 실제 업무 데이터는 구글 시트 · 공공 서비스 · 웹페이지에 흩어져 있습니다. 오늘은 세 곳에서 데이터를 코드를 저장하지 않고 말(프롬프트)로 가져와, 내 구글 시트 한 파일에 탭으로 쌓습니다.

끝나면 이렇게 됩니다
  • 구글 시트를 커넥터(MCP)로 연결해, 파일을 내려받지 않고 Claude 가 바로 읽게 했다.
  • 커넥터가 없는 법령 정보를 API 키로 받아 왔고, 키를 채팅에 붙이지 않고 .env 에 두는 습관을 들였다.
  • API 도 커넥터도 없는 교육청 학원 공고를 허락부터 확인하고 가져와, 빠짐없이 왔는지 검산했다.
  • API · 크롤링 결과가 내 구글 시트에 탭으로 쌓였다(개인정보보호법 · 학원공고).

모든 단계가 같은 틀입니다

  1. 가져오기 — 카드를 복사해 붙여넣습니다. Claude 가 알아서 가져옵니다.
  2. 확인 — 제대로, 빠짐없이 왔는지 봅니다. 오류가 없다고 다 맞는 것은 아닙니다.
  3. 저장 — 작업 폴더에 CSV 파일로 남깁니다. API · 크롤링 결과는 4단계 내 구글 시트에 탭으로도 올립니다(5 · 8단계).
매일 저절로 돌게 하려면오늘은 매번 말로 시킵니다. 같은 수집을 스크립트로 저장해 매일 정해진 시각에 돌리고, 결과를 슬랙으로 알려 받는 자동화는 Advance 과정에서 합니다.

① 준비 1~2단계 · 15분

PART 1준비 (1~2단계)

VS Code(또는 Cursor)에서 교육 편 작업 폴더를 열면 준비 끝입니다. 오늘 만드는 파일(CSV · .env)은 모두 이 폴더에 생깁니다.

1

Python 설치

Claude 는 데이터를 가져오고 정리할 때 먼저 Python 을 고릅니다. API 호출 · 웹페이지 읽기 · CSV 저장도 Python 으로 짧게 끝납니다. 설치가 안 돼도 1~7단계는 진행됩니다 — 막히면 넘어가고 강사에게 알립니다.

방법
  1. python.org Windows 다운로드 에서 Stable Releases(왼쪽) 아래 맨 위 Python 3.x.x 항목의 Windows installer (64-bit) 를 받습니다. 그 위의 Python install manager 는 받지 않습니다 — 아래 2번의 PATH 체크 화면이 없는 다른 설치 방식입니다.
  2. 설치 파일을 열고 첫 화면 맨 아래 「Add python.exe to PATH」를 체크한 뒤 Install Now. 내 계정에만 깔리는 방식이라 관리자 권한이 없어도 됩니다.
  3. VS Code 를 껐다 켜고(새 터미널이라야 Python 을 찾습니다) claude → 붙여넣습니다.
    python --version 이 되는지 확인해 줘. 안 되면 무엇이 문제인지만 알려 주고, 아무것도 설치하지는 마.
확인

Python 3. 으로 시작하는 버전 번호가 나온다.

왜 Python 을 쓰나요① 표 · CSV · 엑셀처럼 데이터를 다루는 도구가 가장 많은 언어라, 가져온 데이터를 정리하고 파일로 저장하는 일이 짧은 코드로 끝납니다. ② 데이터 작업에서 가장 널리 쓰여 Claude 가 가장 익숙하게 짜는 언어입니다 — 그래서 시키면 Python 부터 고르고, 틀리는 일도 적습니다. ③ 오늘 만든 수집 코드를 매일 자동으로 돌리는 Advance 과정에서도 그대로 이어서 씁니다.
2

법령 API 키 신청 해 보기

API 를 쓰려면 서비스에 가입하고 활용 신청을 해서 승인을 받아야 합니다. 이 서비스는 신청하면 바로 자동 승인됩니다. 오늘 실습은 강사가 알려 주는 교육용 키(5단계에서 .env 에 넣습니다)로 하고, 여기서는 신청 절차를 직접 한 번 해 봅니다.

방법
  1. 국가법령정보 공동활용(open.law.go.kr) 에 회원가입하고 로그인합니다.
  2. 상단 메뉴의 OPEN API → OPEN API 신청으로 갑니다.
  3. 활용 목적에 「업무 자료 조회 교육 실습」처럼 적고, 화면이 요구하는 항목을 채워 신청합니다. 무엇을 넣을지 모르겠으면 강사 화면을 따라 합니다.
  4. API인증키(OC) 칸에 가입한 이메일의 @ 앞부분을 넣고 [중복확인]을 누릅니다. 이미 쓰는 값이라고 나오면 뒤에 글자를 조금 붙입니다.
  5. 공동활용 법령종류는 맨 위 「전체선택」을 체크합니다. 최소한 대한민국 현행법령 → 목록 JSON 은 체크돼 있어야 5단계 법령 조회가 됩니다.
  6. 신청 내역에서 승인여부가 「승인」, 활용상태가 「연결」로 보이면 끝입니다. 바로 보입니다.
확인

신청 내역에 내 신청이 승인여부 「승인」으로 한 줄 보인다.

OC 가 뭔가요이 API 의 키는 OC 라는 이름으로, 신청 때 직접 정한 값(이메일 @ 앞부분)이 그대로 키입니다. 따로 발급되는 긴 키는 없고, 잊으면 마이페이지 → API인증키관리에서 봅니다. 자동 승인이라 .env 의 교육용 OC 를 내 것으로 바로 바꿔 끼워도 됩니다.

PART 2MCP — 커넥터로 가져오기 (3~4단계)

MCP 는 Claude 에 붙이는 손발입니다. 붙이는 방법은 여러 가지인데, 오늘은 가장 쉬운 커넥터 하나만 직접 해 봅니다.

3

MCP 종류 보기 · 구글 커넥터 연결

종류붙이는 법예시오늘
커넥터claude.ai 설정에서 로그인만 한다. 같은 계정의 Claude Code 에 따라온다Google Drive · Gmail · 캘린더 · 슬랙 · 노션직접 연결
원격 MCP서비스가 주는 주소를 claude mcp add 로 등록한다업무 도구 회사가 제공하는 MCP이름만
로컬 MCP내 PC 에 설치하고 claude mcp add 로 등록한다DB 조회 · 크롬 조종이름만
방법
  1. 브라우저에서 claude.ai 에 로그인 → 왼쪽 아래 내 이름 → 설정 → 커넥터.
  2. Google Drive 와 Google Sheets 를 각각 연결하고, 회사 구글 계정으로 로그인해 권한을 허용합니다. 시트 안의 칸을 쓰고 지우는 것은 Google Sheets 연결이 합니다.
  3. VS Code 터미널에서 Claude Code 를 다시 켭니다(exit → claude). 그다음 /mcp 를 입력합니다.
확인

/mcp 목록에 Google Drive 와 Google Sheets 가 둘 다 연결된 상태로 보인다.

허용 화면에서 막히면회사 계정은 관리자가 외부 앱 연결을 막아 두었을 수 있습니다. 4단계는 강사 화면으로 보고 5단계로 넘어갑니다.
연결하면 볼 수 있는 범위커넥터를 연결하면 Claude 가 내 드라이브 전체를 볼 수 있습니다. 시킬 때는 파일 이름을 콕 집어 말합니다.
4

내 구글 시트에 시트 만들고 데이터 넣기

진행자가 내 이름으로 된 구글 시트를 하나씩 만들어 두었습니다. 브라우저에서 열고 주소창의 링크를 복사한 뒤, Claude Code 에 링크를 붙여넣고 아래 두 가지를 내 말로 이어서 적습니다.

방법
  1. 시트 만들기 — 그 파일 안에 새 시트(아래쪽 탭)를 만들어 달라고 합니다. 예) 「이번주일정이라는 시트를 만들어줘」
  2. 데이터 넣기 — 만든 시트에 넣을 데이터를 말합니다. 예) 「우리 팀 이번 주 일정을 5줄 넣어줘」. 끝에 「같은 내용을 이 폴더에 시트.csv 로도 저장해 줘」를 덧붙입니다 — 단계 끝은 CSV 로 남기는 것이 오늘의 같은 틀입니다.

보내는 모양 예시:
https://docs.google.com/spreadsheets/d/…(내 시트 링크)
1. 이번주일정이라는 시트를 만들어줘
2. 우리 팀 이번 주 일정을 5줄 넣어줘. 같은 내용을 이 폴더에 시트.csv 로도 저장해 줘

데이터는 내가 내용을 주거나 지어내도 되는 것으로 합니다 — 날씨처럼 바깥에서 가져와야 하는 데이터는 출처가 없어 값을 지어낼 수 있고, 그건 5단계(API)의 몫입니다.

확인

브라우저의 내 시트 아래쪽에 새 탭이 생겼고, 그 안에 시킨 데이터가 들어 있다. 이 폴더에 시트.csv 가 생겼다.

「Read outside the working directories」 창이 뜨면Claude 가 구글 시트 사용법 안내서(스킬)를 읽으러 작업 폴더 밖으로 나가서 묻는 창입니다. 1번(Yes, and keep allowing)을 고릅니다. 읽기만 허용되고, 다음부터는 묻지 않습니다.
링크로 콕 집어 말하는 이유오늘은 여러 사람이 같은 연결로 실습합니다. 시트 이름만 말하면 다른 사람 시트를 건드릴 수 있으니 내 시트 링크를 붙여서 시킵니다.
③ API 5단계 · 15분

PART 3API — 키로 받아 오기 (5단계)

법령 정보는 커넥터가 없습니다. 대신 국가법령정보가 API 를 열어 두었습니다. 키(OC)를 들고 가서 받아 옵니다. 키는 먼저 .env 파일의 LAW_OC 에 넣어 둡니다 — 코드와 채팅에 키를 직접 쓰지 않으려는 것입니다.

5

개인정보 보호법 확인 · 시트에 넣기

오늘은 개인정보 보호법 조문을 API 로 받아, 사람인 같은 채용 사이트에서 데이터를 모으면 이 법에 걸리는지 Claude 에게 확인시킵니다 — 7단계에서 할 수집 전에 법부터 보는 연습입니다. 부서마다 자주 보는 법은 아래 표와 같습니다. 끝난 뒤 내 부서 법으로 바꿔 물어봐도 됩니다.

부서법령 이름
직영 · 가맹 사업부학원의 설립ㆍ운영 및 과외교습에 관한 법률
출판출판문화산업 진흥법
재무부가가치세법
마컴표시ㆍ광고의 공정화에 관한 법률
연구소저작권법
방법
  1. .env 만들기 — 붙여넣습니다. 값은 비워 둔 칸만 만들게 합니다.
    이 폴더 맨 위에 .env 파일을 만들고 LAW_OC= 한 줄을 넣어 줘. 값은 비워 둬. 이미 .env 가 있으면 다른 줄은 건드리지 말고 LAW_OC= 줄만 추가해 줘. 새 프로그램은 설치하지 마.
  2. 왼쪽 탐색기에서 .env 를 열고 LAW_OC= 바로 뒤에 강사가 알려 준 OC 를 붙여 씁니다(따옴표 · 띄어쓰기 없이). 윈도우 단축키 Ctrl+S 로 저장합니다(맥은 Cmd+S). 위쪽 탭의 파일 이름 옆 ● 가 사라지면 저장된 것입니다. 키는 채팅이 아니라 파일에 직접 씁니다.
  3. 법령 조회 — 그대로 붙여넣습니다. 1~2분 걸립니다.
    법령은 개인정보 보호법을 찾아보자. 이 폴더 .env 의 LAW_OC 를 OC 값으로 써서 국가법령정보 OPEN API(http://www.law.go.kr/DRF/lawSearch.do · target=law · type=JSON)에서 그 법령을 찾고, 본문 API(http://www.law.go.kr/DRF/lawService.do · target=law · type=JSON)로 조문을 받아 줘. 그 조문을 근거로 「사람인 같은 채용 사이트에서 데이터를 수집하면 개인정보 보호법에 걸리는지」 확인해 줘. 근거 조문 번호 · 조문 제목 · 핵심 내용 · 수집과의 관계를 표로 보여 주고, law 폴더를 만들어서 법령.csv 로 저장해 줘. OC 값은 화면에 쓰지 마. 판례는 조회하지 마.
  4. 구글 시트에 넣기 — 4단계에서 쓴 내 이름 구글 시트 링크를 맨 앞에 붙이고, 이어서 붙여넣습니다. API 로 받은 결과를 MCP 로 시트에 쌓는 것입니다.
    이 구글 시트 파일 안에 「개인정보보호법」이라는 시트를 새로 만들고, 이 폴더 law 폴더의 법령.csv 내용을 첫 줄 제목까지 그대로 넣어 줘. 다 되면 넣은 행 수가 CSV 행 수와 같은지 알려 줘.
확인

근거 조문 표(조문 번호 · 제목 · 핵심 내용 · 수집과의 관계)가 화면과 law\법령.csv 에 같이 들어 있다. 내 구글 시트 아래쪽에 「개인정보보호법」 탭이 생겼고, 행 수가 CSV 와 같다. 표에서 조문 하나(예: 제15조)를 골라 국가법령정보센터 원문과 내용이 맞는지 한 번 대조한다.

주의조회 결과는 법률 자문이 아닙니다. 업무 판단은 원문과 담당 부서 확인을 거칩니다.
심화 — 바뀐 내용까지 받아 보기

「방금 찾은 법령의 본문 API(lawService.do)로 최근 개정 이유를 받아 3줄로 요약해 줘」라고 이어서 시킵니다. 판례 본문은 화면이 늦게 채워지는 구조라 이 방법으로는 잘 안 옵니다 — 그래서 오늘은 법령만 봅니다.

PART 4크롤링 — 화면에서 가져와 시트에 적재 (6~8단계)

6

가져와도 되는지 먼저 확인

사이트는 robots.txt 라는 파일에 「자동으로 가져가도 되는 곳 · 안 되는 곳」을 적어 둡니다. 같은 교육청 사이트라도 답이 다릅니다.

강사 시연

강사가 robots.txt 로 게시판을 막아 둔 교육청을 보여 줍니다. 「여기는 확인만 하고 가져오지 않는다」로 끝냅니다. 따라 하지 않습니다.

방법
  1. 붙여넣습니다.
    https://www.sen.go.kr/robots.txt 를 읽고, 서울시교육청 고시·공고 게시판에서 「학원」으로 검색한 목록 https://www.sen.go.kr/user/bbs/BD_selectBbsList.do?q_bbsSn=1100&q_searchKeyTy=ttl___1002&q_searchVal=학원 과, 목록의 글을 눌렀을 때 열리는 상세 글 주소(BD_selectBbs.do) 를 자동으로 가져와도 되는지 판단해 줘. 근거가 된 줄을 그대로 보여 줘. 아직 목록은 가져오지 마. 새 프로그램은 설치하지 마.
확인

「Allow: / 가 있고, 막아 둔 게시판 번호(q_bbsSn=1079~1091)에 이 게시판(1100)이 없어 목록 · 상세 글 둘 다 가져와도 된다」와 근거 줄이 나온다. 게시판마다 허락이 다를 수 있어 번호까지 본다.

하지 않는 것로그인해야 보이는 페이지 · 개인정보가 있는 페이지 · robots.txt 나 이용 약관이 막은 페이지. 한 번에 수십 페이지를 가져오지 않습니다(오늘은 목록 1페이지만).
7

학원 공고 목록 → 검산 → 저장

방법
  1. 붙여넣습니다. 목록 저장 → 검산 → 관련 판단 → 관련 글만 본문 요약을 1 · 2 · 3 · 4 순서로 한 번에 시킵니다(2분 남짓). 2번 검산에서 숫자가 안 맞으면 Claude 가 멈추고 이유를 알려 줍니다.
    서울시교육청 고시·공고 게시판의 「학원」 검색 목록 1페이지 https://www.sen.go.kr/user/bbs/BD_selectBbsList.do?q_bbsSn=1100&q_searchKeyTy=ttl___1002&q_searchVal=학원 를 아래 순서로 정리해 줘. 1. 요약하지 말고 원본 HTML 그대로 받아서, 글마다 번호 · 부서 · 제목 · 날짜 · 링크(https 로 시작하는 전체 주소)를 crawling 폴더를 만들어서 학원공고.csv 로 저장해 줘. 작성자 이름은 저장하지 마. 2. CSV 의 글 수와 페이지에 보이는 글 수를 비교하고, 번호가 빠짐없이 이어지는지 확인해 줘. 다르면 이유를 알려 주고 여기서 멈춰. 3. 「관련」 열을 추가해서, 제목을 보고 학원 · 교습소 운영과 관련된 공고면 O, 「대학원」 「학교법인 ○○학원」처럼 이름에 학원이 들어갔을 뿐인 글이면 빈칸으로 채워 줘. 4. 「관련」이 O 인 글만 「링크」 열의 상세 페이지를 하나씩 열어 제목 아래 본문 영역만 읽고, 3줄로 요약해서 「본문 요약」 열에 넣어 줘. 사이트 메뉴 글자와 작성자 이름은 빼고, 본문이 짧고 내용이 첨부파일에만 있으면 「내용은 첨부에 있음」이라고 적어 줘. 첨부파일은 받지 말고, 글 사이에 1초씩 쉬어 줘. 다 되면 글 수 비교 결과, 관련 글 수, 빈칸으로 둔 글을 뺀 이유, 요약을 채운 글 수가 O 개수와 같은지 알려 줘. 새 프로그램은 설치하지 마.
확인

crawling\학원공고.csv 가 생겼고, 글 수(10)가 페이지와 같고 번호가 빠짐없이 이어진다. 작성자 이름 열이 없다. 「관련」 열이 채워졌고, 대학원 · 학교법인 공고는 이유와 함께 빠졌다. 「본문 요약」이 O 글 수만큼 채워졌고(입법예고처럼 내용이 첨부에만 있는 글은 「내용은 첨부에 있음」), 요약에 작성자 이름이 없다.

「학원」으로 찾았는데 대학원이 섞였다면게시판 검색은 글자로 찾아서 「대학원」 「학교법인 경남학원」도 걸립니다. 그대로 쓰면 학원 공고가 실제보다 많아 보입니다. 오류 없이 끝났다고 맞게 가져온 것은 아닙니다 — 그래서 글 수 · 번호를 검산하고, 뜻은 Claude 에게 한 번 더 고르게 합니다. 페이지 위 「전체 45건」은 검색 결과 전체이고, 오늘은 1페이지 10건만 가져옵니다.
심화 — 판단을 AI 가 하는 이유

「학원 운영과 관련 있나」는 제목에 「학원」이 있어도 아닐 수 있고(대학원 · 학교법인), 없어도 맞을 수 있습니다(예: 「교습소 · 개인과외 신고 안내」). 단어 검색으로는 못 하는 일이라, 크롤링에 Claude 를 붙이는 이유가 여기 있습니다.

확인

내 시트에 「학원공고」 탭이 하나 있고, 행 수가 CSV 와 같다(제목 포함 11행). 「관련」 · 「본문 요약」 열도 그대로 들어 있다. 두 번 돌려도 탭이 하나다.

구글 연결이 안 됐다면3단계를 강사 화면으로 넘겼다면 이 단계도 강사 화면으로 봅니다. crawling\학원공고.csv 가 남아 있으면 오늘 수집은 끝난 것입니다.

9

수집 결과 페이지 배포

5단계 법령과 7단계 학원 공고를 웹페이지 한 장으로 만들어 동료에게 보여 줍니다. 같은 페이지라도 어디에 올리느냐에 따라 누가 보는지 · 언제까지 열리는지가 다릅니다. 세 가지로 내보내 보고 비교합니다.

방법
  1. 페이지 만들기 — 붙여넣습니다. 1분 남짓 걸립니다. 다 되면 탐색기에서 publish\index.html 을 오른쪽 클릭 → Reveal in File Explorer(파일 탐색기에 표시) → 더블클릭해 브라우저로 봅니다.
    law\법령.csv 와 crawling\학원공고.csv 로 결과 페이지를 publish\index.html 한 파일로 만들어. 외부 파일 · 인터넷 라이브러리 없이 한 장에 다 넣고, 맨 위에 수집 날짜와 출처를 적어. 링크는 누르면 새 창으로 열리게 해. 새 프로그램은 설치하지 마
  2. 구글 웹앱으로 배포 — 회사 구글 계정으로 script.google.com → 새 프로젝트.
    1. Code.gs 내용을 지우고 아래를 붙여넣습니다.
      function doGet() { return HtmlService.createHtmlOutputFromFile('수집결과').setTitle('수집 결과'); }
    2. 파일 옆 + → HTML → 이름 수집결과. VS Code 에서 publish\index.html 을 열어 Ctrl+A · Ctrl+C → 새 HTML 파일 내용을 지우고 붙여넣고 저장합니다.
    3. 배포 → 새 배포 → 유형 웹 앱 → 아래 표대로 고르고 배포 → 승인 → 웹앱 주소를 동료에게 보냅니다.
  3. Claude 아티팩트로 배포 — 붙여넣습니다. 게시한 페이지는 처음엔 나만 봅니다. 받은 링크를 열어 공유를 켠 뒤 동료에게 보냅니다.
    publish\index.html 을 Claude 아티팩트로 게시해 줘. 게시한 링크를 알려 줘.
  4. 사내 로컬 서버로 배포 — 내 PC 를 서버로 띄워 옆자리 동료가 열어 보게 합니다.
    1. 내 IP 주소 알기 — 붙여넣습니다. 나온 주소를 적어 둡니다.
      동료가 내 PC 에 접속할 때 쓸 사내 IP 주소(IPv4)를 하나만 알려 줘. 지금 연결된 와이파이나 유선 것으로 고르고, 설정은 아무것도 바꾸지 마.
    2. 서버 켜기 — Claude 가 돌고 있는 터미널 말고, 터미널 패널 오른쪽 위 + 로 새 터미널을 엽니다. 거기에 그대로 붙여넣고 Enter. Serving HTTP on … port 8000 이 나오면 켜진 것입니다. 이 창은 닫지 않습니다.
      python -m http.server 8000 --directory publish
      Windows 보안 창(방화벽)이 뜨면 허용을 누릅니다.
    3. 동료에게 열어 보게 하기 — http://내IP주소:8000/ 를 메신저로 보냅니다. 동료 화면에 결과 페이지가 바로 열립니다(파일 이름이 index.html 이라 주소 끝에 파일 이름을 붙이지 않아도 됩니다).
    4. 키가 안 새는지 확인 — 동료에게 http://내IP주소:8000/.env 도 열어 보게 합니다. 404 · File not found 가 나와야 맞습니다.
    5. 서버 끄기 — 서버 터미널을 클릭하고 Ctrl+C. 동료가 새로고침하면 이제 안 열립니다.
    PC 만 켜져 있으면 열리나요? — 아닙니다동료가 이 주소를 열 수 있는 건 아래 세 가지가 동시에 맞을 때뿐입니다.
    1. 서버 명령이 돌고 있다 — Ctrl+C, 서버 터미널 닫기, VS Code 닫기, 절전 모드, 재부팅 중 하나라도 하면 꺼집니다. 다시 열려면 2번 명령을 다시 붙여넣습니다.
    2. 내 IP 주소가 그대로다 — 재부팅하거나 다른 와이파이 · 유선으로 바꾸면 주소가 달라질 수 있습니다. 그러면 1번 카드로 새 주소를 확인해 다시 보냅니다.
    3. 동료가 같은 사내망에 있다 — 손님 와이파이 · 재택 · 회사 밖에서는 열리지 않습니다.
    그래서 「어제 보낸 주소가 오늘은 안 열린다」가 흔합니다. 로컬 서버는 지금 옆 사람에게 잠깐 보여 줄 때 씁니다. 늘 열려 있어야 하면 구글 웹앱이나 Claude 아티팩트로 배포합니다(PC 를 자동으로 켜 두고 서버를 저절로 띄우는 것은 Advance 과정에서).
    명령을 치지 않고 Claude 에게 켜고 끄게 하기

    위 2번 명령 대신 아래 카드를 붙여넣으면 Claude 가 서버를 켜고, 주소와 /.env 404 까지 확인해 줍니다. 서버는 따로 창으로 떠서 Claude 를 꺼도 계속 돕니다 — 그 창을 닫거나 끄기 카드를 붙여넣으면 꺼집니다.

    publish 폴더만 사내에서 열리게 8000 포트로 웹 서버를 켜 줘. 작업 폴더 전체나 .env 는 열리면 안 돼. 서버는 따로 창으로 띄워서 네가 꺼져도 계속 돌게 하고, 켜지면 동료에게 보낼 주소(http://내 사내 IP:8000/)를 알려 줘. 그 주소가 열리는지, 주소 끝에 /.env 를 붙이면 404 가 나오는지도 확인해 줘. 새 프로그램은 설치하지 마.

    끌 때:

    아까 켠 8000 포트 웹 서버를 꺼 줘. 다른 프로그램은 건드리지 마. 끈 뒤 그 주소가 더 이상 안 열리는지 확인해 줘.

    창이 따로 떠 있어서 잊고 켜 둔 채 두기 쉽습니다. 다 보여 줬으면 꼭 끕니다.

주의로컬 서버는 띄운 폴더 안의 파일을 전부, 같은 망의 누구에게나 보여 줍니다. 명령 끝의 --directory publish 를 빼면 작업 폴더 전체 — .env(API 키)까지 사내에 열립니다. 이 부분은 지우거나 바꾸지 않습니다. 서버 터미널에서 Ctrl+C 를 누를 것 — Claude 터미널에서 누르면 Claude 가 꺼집니다. 회사 자료로 만든 페이지는 Claude 아티팩트에 올리지 않습니다.
