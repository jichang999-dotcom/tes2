시작 전업무 데이터는 파일 하나에 모여 있지 않습니다

교육 편에서는 받은 CSV 파일 하나로 스킬과 에이전트를 만들었습니다. 실제 업무 데이터는 구글 시트 · 공공 서비스 · 웹페이지에 흩어져 있습니다. 오늘은 세 곳에서 데이터를 코드를 저장하지 않고 말(프롬프트)로 가져와, 마지막에 엑셀 한 파일로 모읍니다.

끝나면 이렇게 됩니다
  • 구글 시트를 커넥터(MCP)로 연결해, 파일을 내려받지 않고 Claude 가 바로 읽게 했다.
  • 커넥터가 없는 법령 정보를 API 키로 받아 왔고, 키를 채팅에 붙이지 않고 .env 에 두는 습관을 들였다.
  • API 도 커넥터도 없는 교육청 보도자료를 허락부터 확인하고 가져와, 빠짐없이 왔는지 검산했다.
  • 세 결과가 엑셀 한 파일(시트 3장)에 모였다.

모든 단계가 같은 틀입니다

  1. 가져오기 — 카드를 복사해 붙여넣습니다. Claude 가 알아서 가져옵니다.
  2. 확인 — 제대로, 빠짐없이 왔는지 봅니다. 오류가 없다고 다 맞는 것은 아닙니다.
  3. 저장 — 작업 폴더에 CSV 파일로 남깁니다. 8단계에서 셋을 엑셀 한 파일로 모읍니다.
매일 저절로 돌게 하려면오늘은 매번 말로 시킵니다. 같은 수집을 스크립트로 저장해 매일 정해진 시각에 돌리고, 결과를 슬랙으로 알려 받는 자동화는 Advance 과정에서 합니다.

① 준비 1~2단계 · 15분

PART 1준비 (1~2단계)

VS Code(또는 Cursor)에서 교육 편 작업 폴더를 열고, 강사가 준 .env 파일을 그 폴더 맨 위에 넣어 둡니다. 탐색기에 .env 가 보이면 준비 끝입니다.

1

Python 설치

Claude 는 데이터를 가져오고 정리할 때 먼저 Python 을 고릅니다. 8단계에서 엑셀 파일을 만들 때도 Python 이 가장 쉽습니다. 설치가 안 돼도 1~7단계는 진행됩니다 — 막히면 넘어가고 강사에게 알립니다.

방법
  1. python.org Windows 다운로드 에서 최신 안정판의 Windows installer (64-bit) 를 받습니다.
  2. 설치 파일을 열고 첫 화면 맨 아래 「Add python.exe to PATH」를 체크한 뒤 Install Now. 내 계정에만 깔리는 방식이라 관리자 권한이 없어도 됩니다.
  3. VS Code 를 껐다 켜고(새 터미널이라야 Python 을 찾습니다) claude → 붙여넣습니다.
    python --version 이 되는지 확인해 줘. 안 되면 무엇이 문제인지만 알려 주고, 아무것도 설치하지는 마.
확인

Python 3. 으로 시작하는 버전 번호가 나온다.

왜 Python 을 쓰나요① 표 · CSV · 엑셀처럼 데이터를 다루는 도구가 가장 많은 언어라, 가져온 데이터를 정리하고 파일로 저장하는 일이 짧은 코드로 끝납니다. ② 데이터 작업에서 가장 널리 쓰여 Claude 가 가장 익숙하게 짜는 언어입니다 — 그래서 시키면 Python 부터 고르고, 틀리는 일도 적습니다. ③ 오늘 만든 수집 코드를 매일 자동으로 돌리는 Advance 과정에서도 그대로 이어서 씁니다.
2

법령 API 키 신청 해 보기

API 를 쓰려면 서비스에 가입하고 활용 신청을 해서 승인을 받아야 합니다. 이 서비스는 신청하면 바로 자동 승인됩니다. 오늘 실습은 강사가 준 교육용 키(받은 .env 안)로 하고, 여기서는 신청 절차를 직접 한 번 해 봅니다.

방법
  1. 국가법령정보 공동활용(open.law.go.kr) 에 회원가입하고 로그인합니다.
  2. 상단 메뉴의 OPEN API → OPEN API 신청으로 갑니다.
  3. 활용 목적에 「업무 자료 조회 교육 실습」처럼 적고, 화면이 요구하는 항목을 채워 신청합니다. 무엇을 넣을지 모르겠으면 강사 화면을 따라 합니다.
  4. API인증키(OC) 칸에 가입한 이메일의 @ 앞부분을 넣고 [중복확인]을 누릅니다. 이미 쓰는 값이라고 나오면 뒤에 글자를 조금 붙입니다.
  5. 공동활용 법령종류는 맨 위 「전체선택」을 체크합니다. 최소한 대한민국 현행법령 → 목록 JSON 은 체크돼 있어야 5단계 법령 조회가 됩니다.
  6. 신청 내역에서 승인여부가 「승인」, 활용상태가 「연결」로 보이면 끝입니다. 바로 보입니다.
확인

신청 내역에 내 신청이 승인여부 「승인」으로 한 줄 보인다.

OC 가 뭔가요이 API 의 키는 OC 라는 이름으로, 신청 때 직접 정한 값(이메일 @ 앞부분)이 그대로 키입니다. 따로 발급되는 긴 키는 없고, 잊으면 마이페이지 → API인증키관리에서 봅니다. 자동 승인이라 .env 의 교육용 OC 를 내 것으로 바로 바꿔 끼워도 됩니다.
② MCP 3~4단계 · 15분

PART 2MCP — 커넥터로 가져오기 (3~4단계)

MCP 는 Claude 에 붙이는 손발입니다. 붙이는 방법은 여러 가지인데, 오늘은 가장 쉬운 커넥터 하나만 직접 해 봅니다.

3

MCP 종류 보기 · 구글 커넥터 연결

종류붙이는 법예시오늘
커넥터claude.ai 설정에서 로그인만 한다. 같은 계정의 Claude Code 에 따라온다Google Drive · Gmail · 캘린더 · 슬랙 · 노션직접 연결
원격 MCP서비스가 주는 주소를 claude mcp add 로 등록한다업무 도구 회사가 제공하는 MCP이름만
로컬 MCP내 PC 에 설치하고 claude mcp add 로 등록한다DB 조회 · 크롬 조종이름만
방법
  1. 브라우저에서 claude.ai 에 로그인 → 왼쪽 아래 내 이름 → 설정 → 커넥터.
  2. Google Drive 와 Google Sheets 를 각각 연결하고, 회사 구글 계정으로 로그인해 권한을 허용합니다. 시트 안의 칸을 쓰고 지우는 것은 Google Sheets 연결이 합니다.
  3. VS Code 터미널에서 Claude Code 를 다시 켭니다(exit → claude). 그다음 /mcp 를 입력합니다.
확인

/mcp 목록에 Google Drive 와 Google Sheets 가 둘 다 연결된 상태로 보인다.

허용 화면에서 막히면회사 계정은 관리자가 외부 앱 연결을 막아 두었을 수 있습니다. 4단계는 강사 화면으로 보고 5단계로 넘어갑니다.
연결하면 볼 수 있는 범위커넥터를 연결하면 Claude 가 내 드라이브 전체를 볼 수 있습니다. 시킬 때는 파일 이름을 콕 집어 말합니다.
4

내 구글 시트에 시트 만들고 데이터 넣기

진행자가 내 이름으로 된 구글 시트를 하나씩 만들어 두었습니다. 브라우저에서 열고 주소창의 링크를 복사한 뒤, Claude Code 에 링크를 붙여넣고 아래 두 가지를 내 말로 이어서 적습니다.

방법
  1. 시트 만들기 — 그 파일 안에 새 시트(아래쪽 탭)를 만들어 달라고 합니다. 예) 「이번주일정이라는 시트를 만들어줘」
  2. 데이터 넣기 — 만든 시트에 넣을 데이터를 말합니다. 예) 「우리 팀 이번 주 일정을 5줄 넣어줘」. 끝에 「같은 내용을 이 폴더에 시트.csv 로도 저장해 줘」를 덧붙입니다 — 8단계에서 씁니다.

보내는 모양 예시:
https://docs.google.com/spreadsheets/d/…(내 시트 링크)
1. 이번주일정이라는 시트를 만들어줘
2. 우리 팀 이번 주 일정을 5줄 넣어줘. 같은 내용을 이 폴더에 시트.csv 로도 저장해 줘

데이터는 내가 내용을 주거나 지어내도 되는 것으로 합니다 — 날씨처럼 바깥에서 가져와야 하는 데이터는 출처가 없어 값을 지어낼 수 있고, 그건 5단계(API)의 몫입니다.

확인

브라우저의 내 시트 아래쪽에 새 탭이 생겼고, 그 안에 시킨 데이터가 들어 있다. 이 폴더에 시트.csv 가 생겼다.

「Read outside the working directories」 창이 뜨면Claude 가 구글 시트 사용법 안내서(스킬)를 읽으러 작업 폴더 밖으로 나가서 묻는 창입니다. 1번(Yes, and keep allowing)을 고릅니다. 읽기만 허용되고, 다음부터는 묻지 않습니다.
링크로 콕 집어 말하는 이유오늘은 여러 사람이 같은 연결로 실습합니다. 시트 이름만 말하면 다른 사람 시트를 건드릴 수 있으니 내 시트 링크를 붙여서 시킵니다.
③ API 5단계 · 15분

PART 3API — 키로 받아 오기 (5단계)

법령 정보는 커넥터가 없습니다. 대신 국가법령정보가 API 를 열어 두었습니다. 키(OC)를 들고 가서 받아 옵니다. 키는 .env 의 LAW_OC 에 있습니다.

5

내 부서 법령 조회 · 저장

부서마다 자주 보는 법이 다릅니다. 아래에서 내 부서 법령 하나를 고릅니다. 카드는 같고 법령 이름만 바꿉니다.

부서법령 이름
직영 · 가맹 사업부학원의 설립ㆍ운영 및 과외교습에 관한 법률
출판출판문화산업 진흥법
재무부가가치세법
마컴표시ㆍ광고의 공정화에 관한 법률
연구소저작권법
방법
  1. 붙여넣습니다. 「법령 이름」을 위 표에서 고른 것으로 바꿉니다.
    이 폴더 .env 의 LAW_OC 를 OC 값으로 써서 국가법령정보 OPEN API(http://www.law.go.kr/DRF/lawSearch.do · target=law · type=JSON)에서 「법령 이름」을 찾아 줘. 현행 법령의 법령명 · 공포일자 · 시행일자 · 제개정 구분을 표로 보여 주고, 같은 내용을 이 폴더에 법령.csv 로 저장해 줘. OC 값은 화면에 쓰지 마. 판례는 조회하지 마. 새 프로그램은 설치하지 마.
확인

법령 이름 · 공포일자 · 시행일자가 화면과 법령.csv 에 같은 값으로 들어 있다. 국가법령정보센터 에서 같은 법을 검색해 시행일자가 맞는지 한 번 대조한다.

주의조회 결과는 법률 자문이 아닙니다. 업무 판단은 원문과 담당 부서 확인을 거칩니다.
심화 — 바뀐 내용까지 받아 보기

「방금 찾은 법령의 본문 API(lawService.do)로 최근 개정 이유를 받아 3줄로 요약해 줘」라고 이어서 시킵니다. 판례 본문은 화면이 늦게 채워지는 구조라 이 방법으로는 잘 안 옵니다 — 그래서 오늘은 법령만 봅니다.

④ 크롤링 6~7단계 · 20분

PART 4크롤링 — 화면에서 가져오기 (6~7단계)

교육청 보도자료는 커넥터도 API 도 없습니다. 사람이 보는 웹페이지에서 가져와야 합니다. 크롤링은 긁는 법보다 두 가지 습관이 중요합니다 — ① 가져와도 되는지 먼저 확인, ② 빠짐없이 왔는지 검산.

6

가져와도 되는지 먼저 확인

사이트는 robots.txt 라는 파일에 「자동으로 가져가도 되는 곳 · 안 되는 곳」을 적어 둡니다. 같은 교육청 사이트라도 답이 다릅니다.

강사 시연

강사가 robots.txt 로 게시판을 막아 둔 교육청을 보여 줍니다. 「여기는 확인만 하고 가져오지 않는다」로 끝냅니다. 따라 하지 않습니다.

방법
  1. 붙여넣습니다.
    https://enews.sen.go.kr/robots.txt 를 읽고, 서울시교육청 보도자료 목록 https://enews.sen.go.kr/news/list.do?step1=3&step2=1 을 자동으로 가져와도 되는지 판단해 줘. 근거가 된 줄을 그대로 보여 줘. 아직 목록은 가져오지 마. 새 프로그램은 설치하지 마.
확인

「/news/ 가 허용(Allow)돼 있어 가져와도 된다」와 근거 줄이 나온다.

하지 않는 것로그인해야 보이는 페이지 · 개인정보가 있는 페이지 · robots.txt 나 이용 약관이 막은 페이지. 한 번에 수십 페이지를 가져오지 않습니다(오늘은 목록 1페이지만).
7

보도자료 목록 → 검산 → 저장

방법
  1. 붙여넣습니다.
    서울시교육청 보도자료 목록 1페이지 https://enews.sen.go.kr/news/list.do?step1=3&step2=1 를 요약하지 말고 원본 HTML 그대로 받아서, 글마다 제목 · 날짜 · 링크를 보도자료.csv 로 저장해 줘. 저장한 뒤 CSV 의 글 수와 페이지에 보이는 글 수를 비교해서, 다르면 이유를 알려 줘. 새 프로그램은 설치하지 마.
  2. 글 수가 맞으면 붙여넣습니다.
    보도자료.csv 에 「관련」 열을 추가해서, 제목을 보고 수학 · 과학 · 입시 · 진로와 관련된 글이면 O, 아니면 빈칸으로 채워 줘. 관련 글이 몇 개인지와 그 제목을 보여 줘.
확인

CSV 글 수가 페이지에 보이는 글 수와 같다. 「관련」 열이 채워졌다.

글 수가 두 배로 나왔다면이 페이지는 같은 글이 카드 모양과 목록 모양으로 두 번 들어 있습니다. 그대로 세면 실제보다 두 배가 됩니다. 「같은 글은 하나로 줄여 줘」라고 다시 시킵니다. 오류 없이 끝났다고 맞게 가져온 것은 아닙니다 — 그래서 검산을 합니다.
심화 — 판단을 AI 가 하는 이유

「수학 · 과학 · 입시 관련」은 제목에 그 단어가 없어도 뜻으로 고릅니다(예: 「고교학점제 설명회」 = 입시). 단어 검색으로는 못 하는 일이라, 크롤링에 Claude 를 붙이는 이유가 여기 있습니다.

⑤ 모으기 · 마무리 8~9단계 · 20분

PART 5모으기 · 마무리 (8~9단계)

8

세 결과를 엑셀 한 파일로

수집의 끝은 한곳에 쌓기입니다. 세 길로 가져온 결과를 엑셀 한 파일에 시트 3장으로 모읍니다.

방법
  1. 붙여넣습니다.
    이 폴더의 시트.csv · 법령.csv · 보도자료.csv 를 오늘_수집.xlsx 한 파일로 모아 줘. 시트 이름은 시트 · 법령 · 보도자료로 하고, 첫 줄은 고정하고 열 너비를 내용에 맞춰 줘. python 으로 하고, 엑셀용 도구(openpyxl)가 없으면 설치해도 돼. 다 되면 시트마다 행 수를 CSV 와 비교해서 알려 줘.
  2. 탐색기에서 오늘_수집.xlsx 를 엑셀로 엽니다.
확인

시트가 3장이고, 시트마다 행 수가 CSV 와 같다. 한글이 깨지지 않았다.

Python 이 없으면1단계 설치가 안 된 PC 는 엑셀 대신 「세 CSV 를 오늘_수집 폴더 하나에 모아 줘」로 마칩니다.
없는 파일이 있으면4단계나 5단계를 강사 화면으로 넘겼다면 있는 CSV 만 모읍니다. 카드는 그대로 붙여넣으면 Claude 가 없는 파일을 알려 줍니다.
9

웹앱 배포 다시 보기

입문 체험A 에서 만든 Apps Script 웹앱을 다른 사람이 쓰게 열 때 헷갈리는 세 가지만 다시 봅니다.

설정고를 것차이
액세스 권한조직 내 모든 사용자 / 링크가 있는 모든 사용자회사 자료면 조직 내. 「모든 사용자」는 회사 밖에서도 열린다
실행 계정나 / 웹앱에 액세스하는 사용자「나」면 내 권한으로 시트를 읽고 쓴다. 「액세스하는 사용자」면 그 사람에게 시트 권한이 있어야 한다
고친 뒤 반영배포 관리 → 연필 → 새 버전「새 배포」를 누르면 주소가 바뀌어 나눠 준 링크가 옛 판을 보여 준다
방법
  1. 체험A 웹앱의 Apps Script 편집기를 엽니다(없으면 강사 화면으로 봅니다).
  2. 배포 → 배포 관리에서 위 세 가지가 어떻게 되어 있는지 확인합니다.
  3. 동료에게 웹앱 주소를 보내 동료 계정으로 열리는지 봅니다.
확인

동료 계정으로 웹앱이 열린다. 「새 배포」와 「새 버전」의 차이를 말할 수 있다.

PART 6막혔을 때

증상원인해결
「.env 가 없다」고 한다다른 폴더를 열었다 · 파일을 폴더 맨 위가 아닌 곳에 넣었다탐색기 맨 위에 .env 가 보이는지 확인 · 그 폴더에서 claude
/mcp 에 Google Drive 가 없다연결 뒤 Claude Code 를 다시 켜지 않았다 · 다른 계정으로 로그인했다exit → claude · claude.ai 와 Claude Code 가 같은 계정인지 확인
시트를 못 찾는다공유받은 시트를 한 번도 열지 않았다 · 이름이 다르다브라우저로 시트를 한 번 열고, 이름을 그대로 복사해 다시 시킨다
법령 조회에서 「사용자 정보 검증에 실패」OC 값이 틀렸다 · 내 OC 로 바꿨다면 철자가 다르다받은 .env 원본의 교육용 OC 로 되돌린다
법령이 여러 개 나온다이름이 비슷한 시행령 · 시행규칙이 같이 걸렸다「법률만」이라고 덧붙인다
크롤링 CSV 글 수가 두 배다같은 글이 카드 · 목록 두 모양으로 들어 있다「같은 글은 하나로 줄여 줘」
CSV 를 엑셀로 열면 한글이 깨진다BOM 없는 UTF-8 로 저장됐다「엑셀에서 한글이 안 깨지게 UTF-8 BOM 으로 다시 저장해 줘」
8단계에서 엑셀 파일을 못 만든다Python 이 없다 · 회사 PC 가 도구(openpyxl) 설치를 막았다「세 CSV 를 오늘_수집 폴더 하나에 모아 줘」로 마친다
1~7단계에서 Claude 가 프로그램(라이브러리)을 설치하자고 한다카드의 「새 프로그램은 설치하지 마」가 빠졌다거절하고 카드를 그대로 다시 붙여넣는다
python --version 이 안 된다 · 스토어 창이 뜬다설치 때 「Add python.exe to PATH」를 체크하지 않았다 · 터미널을 새로 열지 않았다VS Code 를 껐다 켠다. 그래도 안 되면 설치 파일을 다시 열어 Uninstall → 체크하고 다시 설치
Claude 가 python3 을 쓰다 막힌다윈도우의 python3 은 스토어 바로가기다「python3 말고 python 으로 해」
