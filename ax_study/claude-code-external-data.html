리뷰 그림의 1 수집 단계입니다. 실제 업무 데이터는 한 파일에 모여 있지 않습니다 — 누구나 보는 웹페이지에, 팀이 쓰는 구글 시트 · 드라이브 · 문서에, 매일 들어가는 회사 그룹웨어에 흩어져 있습니다. 오늘은 이 세 곳에서 데이터를 가져와 내 구글 시트 한 곳에 모읍니다. 모은 것을 정리하고 보여 주고 공유하는 일은 다음 가이드(2 전처리 · 3 결과물 · 4 발행 · 공유)에서 합니다. 코드는 직접 짜지 않습니다 — 카드 문장을 붙여넣어 Claude 에게 말로 시키기만 합니다.

PART 1MCP — 웹 브라우저 조종 (1단계)

MCP 는 Claude 에 붙이는 손발입니다. 오늘은 그중 브라우저 조종 두 가지(Claude in Chrome · Playwright)를 붙여, Claude 가 웹페이지를 직접 열고 읽게 합니다. 여기서 붙인 Claude in Chrome 은 2단계(구글 API 설정)와 5~7단계(그룹웨어)에서도 씁니다.

1

준비
  • 크롬 브라우저 · Node.js 18 이상(Playwright) — 없거나 낮으면 프롬프트가 멈추고 안내합니다.
  • 확장 설치 · 로그인은 사람이 직접 합니다. Claude 는 방법을 알려 주고 기다립니다.

방법
  1. 설치 ① Claude in Chrome. Claude Code 에 그대로 붙여넣습니다.
    Claude in Chrome 설치와 연결을 도와줘. 설치·연결만 하고 다른 작업은 하지 마. 끝나면 결과를 표로 보고해줘. 1. 먼저 Claude in Chrome 이 이미 연결돼 있는지 확인해. 연결돼 있으면 5번으로 가. 2. 안 돼 있으면 Chrome 웹 스토어에서 Claude 확장 설치 → Claude Code 와 같은 claude.ai 계정 · 같은 조직으로 로그인 → claude --chrome 으로 다시 켜서 연결하는 방법을 단계별로 알려줘. 연결 상태는 /chrome 으로 확인해. 3. 설치·로그인은 내가 직접 할게. 내가 "연결했어"라고 하면 다시 확인해. 4. 그래도 안 되면 이유(확장 미설치 / 다른 Claude 계정이나 다른 조직으로 로그인 / 크롬 꺼짐 / API 키로 로그인 등)를 짐작해서 알려줘. 5. 확인은 새 탭 하나를 열어 https://example.com 제목만 읽고 그 탭을 닫는 것까지만 해. 내가 연 탭은 건드리지 마.
  2. 설치 ② Playwright MCP. 이어서 붙여넣습니다.
    Playwright MCP 를 설치해줘. 설치만 하고 다른 작업은 하지 마. 명령은 PowerShell 로 실행해. 끝나면 결과를 표로 보고해줘. 1. node -v 로 Node.js 를 확인해. 없거나 18 미만이면 직접 설치하지 말고 멈춘 뒤 강사에게 문의하라고 알려줘. 2. claude mcp list 로 playwright 가 이미 등록돼 있는지 확인해. 있으면 3번은 건너뛰어. 3. 아래 명령으로 등록해줘. 윈도우는 cmd /c 가 있어야 실행돼. claude mcp add -s user playwright -- cmd /c npx -y @playwright/mcp@latest 설치가 실패하면 오류 문구를 그대로 보여주고 멈춰. 4. claude mcp list 에서 playwright 가 Connected 인지 확인해줘. Failed 면 /mcp reconnect all 로 다시 연결한 뒤 한 번만 다시 확인해 (첫 다운로드가 느릴 수 있음). 5. 새 도구는 Claude Code 를 다시 켜야 보인다고 알려줘. 다시 켠 뒤 /mcp 에서 playwright 를 확인하라고도 알려줘.
    프롬프트 줄왜 넣었나
    명령은 PowerShell 로Git Bash 로 실행하면 /c 가 C:/ 경로로 바뀌어 명령이 깨질 수 있다
    -s user지금 연 폴더만이 아니라 모든 폴더에서 playwright 를 쓴다. 빼면 다른 폴더에서 열었을 때 안 보인다
    18 미만이면 멈춤Playwright MCP 는 Node 18 이상에서만 돈다
    Failed 면 한 번 더처음엔 npx 가 내려받느라 느려 연결 확인이 먼저 끝날 수 있다
  3. 다시 시작. Claude Code 를 껐다 켜고(exit → claude --chrome) /mcp 에서 playwright 가 connected, /chrome 에서 연결됨인지 봅니다.
  4. 실습 — 구글 뉴스 한 달 요약. 주제: 줄에 내가 알고 싶은 주제를 넣고 붙여넣습니다.
    구글 뉴스에서 아래 주제의 최근 1개월 뉴스를 모아 요약해줘. 브라우저는 Playwright MCP 로 움직이고, 검색 · 읽기만 해. 로그인 · 글쓰기 · 구독 같은 입력은 하지 마. 주제: (여기에 원하는 주제. 예: 초등 수학 교육) 1. 주제를 주소에 맞게 넣어 https://news.google.com/search?q=주제%20when%3A30d&hl=ko&gl=KR&ceid=KR%3Ako 를 열어. when:30d 가 최근 30일이야. 2. 「로봇이 아닙니다」 같은 확인 화면이 뜨면 우회하지 말고 멈춰. 내가 그 창에서 직접 풀고 "됐어"라고 하면 이어서 해. 3. 목록에서 기사 제목 · 언론사 · 날짜 · 링크를 최대 20건 읽어. 30일보다 오래된 것은 빼고, 같은 소식을 여러 언론사가 쓴 것은 하나로 묶어. 4. 이 폴더 news 안에 뉴스_주제.csv 로 저장해 (열: 날짜, 언론사, 제목, 링크). 5. 묶은 소식 가운데 중요한 5개만 기사를 열어 각각 3줄로 요약해. 기사 문장을 길게 그대로 옮기지 마. 6. 끝나면 브라우저를 닫고 표로 보고해줘: 모은 건수 · 이번 달 흐름 3줄 · 중요 소식 5개 요약 · CSV 경로.
확인

/mcp 에 playwright 가 connected, /chrome 이 연결됨. 실습에서 새 크롬 창이 떴다 닫히고, 보고 표에 건수 · 흐름 · 요약 5개가 나오며 news\뉴스_주제.csv 의 날짜가 모두 최근 30일 안이다.

주의사항 (4)

실습

  2. 데이터 넣기 — 만든 내 이름 시트에 넣을 데이터를 말합니다. 예) 「그 시트에 우리 팀 이번 주 일정을 5줄 넣어줘」. 끝에 「같은 내용을 이 폴더에 시트.csv 로도 저장해 줘」를 덧붙입니다 — 단계 끝은 CSV 로 남기는 것이 오늘의 같은 틀입니다.

도전과제 법령 API 키 신청 해 보기

API 를 쓰려면 서비스에 가입하고 활용 신청을 해서 승인을 받아야 합니다. 이 서비스는 신청하면 바로 자동 승인됩니다. 오늘 실습은 강사가 알려 주는 교육용 키(다음 도전과제에서 .env 에 넣습니다)로 하고, 여기서는 신청 절차를 직접 한 번 해 봅니다.

방법
  1. 국가법령정보 공동활용(open.law.go.kr) 에 회원가입하고 로그인합니다.
  2. 상단 메뉴의 OPEN API → OPEN API 신청으로 갑니다.
  3. 활용 목적에 「업무 자료 조회 실습」처럼 적고, 화면이 요구하는 항목을 채워 신청합니다. 무엇을 넣을지 모르겠으면 강사 화면을 따라 합니다.
  4. API인증키(OC) 칸에 가입한 이메일의 @ 앞부분을 넣고 [중복확인]을 누릅니다. 이미 쓰는 값이라고 나오면 뒤에 글자를 조금 붙입니다.
  5. 공동활용 법령종류는 맨 위 「전체선택」을 체크합니다. 최소한 대한민국 현행법령 → 목록 JSON 은 체크돼 있어야 다음 도전과제의 법령 조회가 됩니다.
  6. 신청 내역에서 승인여부가 「승인」, 활용상태가 「연결」로 보이면 끝입니다. 바로 보입니다.
확인

신청 내역에 내 신청이 승인여부 「승인」으로 한 줄 보인다.

주의사항 (1)
OC 가 뭔가요이 API 의 키는 OC 라는 이름으로, 신청 때 직접 정한 값(이메일 @ 앞부분)이 그대로 키입니다. 따로 발급되는 긴 키는 없고, 잊으면 마이페이지 → API인증키관리에서 봅니다. 자동 승인이라 .env 의 교육용 OC 를 내 것으로 바로 바꿔 끼워도 됩니다.

  1. .env 만들기 — 붙여넣습니다. 값은 비워 둔 칸만 만들게 합니다.

OC 값은 화면에 쓰지 마. 판례는 조회하지 마.
