시작 전휴대폰으로 시키면 내 PC 가 일하고 답합니다

강사가 쓰는 유삐 봇은 강사 PC 에서 도는 헤르메스(Hermes Agent)와 슬랙 봇을 이은 것입니다. 휴대폰 슬랙으로 말을 걸면 PC 의 헤르메스가 받아서 파일을 읽고 일한 뒤 답합니다. 오늘은 같은 구조의 내 봇을 만들어, master 1step 의 cs_practice 문의 답변을 휴대폰에서 시키고 5줄 보고를 받습니다. 플러그인 · 모드는 강사가 보여 줍니다.

끝나면 이렇게 됩니다
  • 내 PC 에 헤르메스가 깔려 있고, 두뇌로 내 Claude 계정이 연결되어 있다.
  • 내 슬랙 워크스페이스에 내 봇이 있고, 휴대폰에서 DM 을 보내면 봇이 답한다.
  • DM 한 통으로 문의 15건 답변을 시키면 봇이 5줄 보고(✅ / 🔴)로 답한다.

PART 1슬랙 봇 + 헤르메스 (1~3단계)

1

헤르메스 설치 · 내 Claude 연결

강사가 휴대폰으로 유삐에게 말을 걸어 답이 오는 것을 먼저 봅니다. 그 답을 만든 것이 강사 PC 의 헤르메스입니다. 내 PC 에 헤르메스를 깔고 두뇌로 내 Claude 계정을 연결합니다.

방법
  1. 브라우저에서 hermes-agent.nousresearch.com/desktop → Windows 설치 파일(exe)을 받아 실행합니다. 서명이 Nous Research Inc. 인지 확인하고 설치합니다.
  2. 헤르메스를 열고 모델 설정에서 공급자(Provider)를 Anthropic 으로 고른 뒤 로그인(OAuth) → 브라우저에서 내 Claude 계정으로 허용.
  3. 헤르메스 대화창에 한 마디 합니다.
    안녕. 너는 지금 어떤 모델로 답하고 있어? 한 줄로.
확인

헤르메스 창에 Claude 모델 이름이 든 답이 왔다. 오류 문구가 없다.

PowerShell 한 줄 설치는 쓰지 않습니다헤르메스 사이트의 PowerShell 설치(iex(irm …))는 회사 PC 보안 프로그램(안랩 Safe Transaction)이 막습니다. 설치 파일(exe)이 정답입니다. 메뉴 이름은 헤르메스 버전마다 조금 다를 수 있습니다.
「Third-party apps now draw from your extra usage」 가 뜨면extra usage 가 꺼져 있거나 잔액이 0 입니다. claude.ai › 설정 › 사용량 에서 켜고 충전한 뒤 다시 말을 겁니다. Max · Pro 요금제에 여유가 있어도 이 지갑은 따로입니다.
2

내 슬랙 봇 연결

헤르메스가 슬랙 메시지를 받으려면, 슬랙이 메시지를 내 PC 로 밀어 주는 앱(Socket Mode)이 필요합니다. 공개 주소 · 서버는 필요 없습니다. 권한은 설치 전에 다 넣어 둬야 합니다 — 나중에 더하면 다시 설치해야 합니다.

방법
  1. 브라우저에서 api.slack.com/apps → Create New App → From a manifest → 워크스페이스 <내 이름>-ax → JSON 칸을 비우고 아래를 붙여넣은 뒤 「영문이름」 두 곳을 내 영문 이름으로 바꿉니다(받은 정답_헤르메스\manifest.json 과 같음) → Create.
    {"display_information":{"name":"영문이름-hermes"},"features":{"app_home":{"messages_tab_enabled":true,"messages_tab_read_only_enabled":false},"bot_user":{"display_name":"영문이름-hermes","always_online":true}},"oauth_config":{"scopes":{"bot":["app_mentions:read","channels:history","channels:read","chat:write","groups:history","im:history","im:read","im:write","users:read"]}},"settings":{"event_subscriptions":{"bot_events":["app_mention","message.channels","message.groups","message.im"]},"interactivity":{"is_enabled":false},"org_deploy_enabled":false,"socket_mode_enabled":true,"token_rotation_enabled":false}}
  2. 앱 토큰 — 왼쪽 Basic Information → 아래 App-Level Tokens → Generate Token and Scopes → 이름 hermes · Add Scope 에서 connections:write → Generate → xapp- 로 시작하는 값을 복사해 둡니다.
  3. 봇 토큰 — 왼쪽 OAuth & Permissions → Install to Workspace → 허용 → Bot User OAuth Token(xoxb- 로 시작)을 복사합니다.
  4. 헤르메스 메인 화면의 Messaging → Slack 에 봇 토큰 · 앱 토큰을 붙여넣고 저장 · 연결합니다. (Settings 가 아니라 Messaging 패널입니다)
  5. 휴대폰 슬랙 → 앱(또는 검색)에서 영문이름-hermes → 메시지 탭에 안녕, 들리면 한 줄로 답해 줘.
확인

휴대폰 슬랙에 내 봇 이름으로 답이 왔다. PC 헤르메스 창에도 같은 대화가 보인다.

「연결 안 됨」 표시가 늦게 바뀔 때헤르메스 화면의 연결 표시는 늦게 바뀝니다. 휴대폰으로 한 번 말을 걸어 답이 오는지가 진짜 확인입니다.
3

휴대폰에서 일 시키기

유삐 보고는 늘 같은 틀입니다 — 제목 ✅/🔴 · 검증 · 오류 · 처리 · 소요 5줄. 긴 지시는 한 번만 보내 두면, 같은 DM 에서는 휴대폰으로 짧게 이어 시킬 수 있습니다(헤르메스가 같은 대화를 기억합니다).

방법
  1. VS Code 탐색기에서 cs_practice 폴더를 오른쪽 클릭 → 경로 복사.
  2. PC 슬랙(또는 휴대폰)의 봇 DM 에 아래를 붙여넣고, 첫 줄의 경로 자리에 복사한 경로를, 내 이름 자리에 내 이름을 넣어 보냅니다(받은 시키기.txt 와 같음).
    경로 폴더의 문의.txt 15건에 응대규정.md 대로 답변을 써 줘. - 문의.txt · 응대규정.md · 응대규정_옛판.md 는 읽기만 하고 고치지 않는다 - 답변은 같은 폴더에 답변_헤르메스.txt 새 파일로 저장한다 - 다 쓰면 답변마다 응대규정.md 와 다시 대조해 맞는 건수를 센다 - 이 DM 에 5줄로 보고한다: *내 이름 문의 답변* ✅(전부 맞으면) 또는 🔴 / 검증: 15건 중 N건 규정 일치 / 오류: 없음, 또는 문의 번호와 이유 / 처리: 저장한 파일 이름 / 소요: 걸린 시간 - 학생 · 학부모 이름은 보고에 넣지 않는다
  3. 답이 오면 휴대폰에서 같은 DM 에 짧게 이어 시킵니다.
    이번엔 시험이야. 응대규정_옛판.md 대로 답변을 써서 답변_옛판.txt 로 저장하고, 응대규정.md 와 대조만 해. 고치지 말고 같은 5줄로 보고해.
확인

✅ 보고의 검증이 「15건 중 15건」이다. 🔴 보고의 오류에 문의 4 · 9 · 13 이 있다(정답표 [3]). cs_practice 에 답변 파일 두 개가 새로 생겼고 문의.txt · 규정 파일은 그대로다.

답이 오래 걸리면15건을 쓰고 대조하느라 몇 분 걸립니다. 휴대폰을 내려놓아도 PC 가 일합니다. 그동안 헤르메스 창을 닫거나 PC 를 재우지 않습니다.
강사의 유삐는 무엇이 더 있나강사 PC 는 헤르메스를 창 없이 늘 켜 두고(작업 스케줄러), 꺼지면 다시 살리는 장치(워치독)를 붙였습니다. 오늘은 수업 동안만 켜 둡니다.
