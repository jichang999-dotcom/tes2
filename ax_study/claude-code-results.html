PART 1준비

1

정리된 CSV 확인하기

방법

데스크톱 앱 Code 탭에서 basic_data 폴더를 열고(2 전처리와 같은 폴더) 붙여넣습니다.

basic_data\정리 폴더의 월별_지표.csv 와 월별_학년별_학생수.csv 를 확인해 줘. 파일은 고치지 마. 1. 두 파일의 열 이름과 행 수 2. 월별_지표의 달 목록과, 달마다 학년별 학생수를 더한 값이 월별_지표의 학생수와 같은지 3. .env 에 GOOGLE_AUTH_DIR 줄이 있는지 (값은 보여 주지 마)
확인

달 6개(202507~202509 · 202607~202609), 달마다 「같음」, GOOGLE_AUTH_DIR 있음/없음이 나온다.

주의사항 (1)
CSV 가 없으면받은 정답_정리 폴더를 basic_data 안에 넣고 이름을 정리 로 바꿉니다. 정답표 숫자로 만든 같은 파일입니다.
② 구글 시트 2~3단계 · 20분

PART 2구글 시트 — 표로 쌓고 직접 거른다

시트의 힘은 받는 사람이 직접 만질 수 있다는 것입니다. 그래서 숫자를 값으로 박아 넣기보다, 계산은 수식으로 남겨 사람이 고치고 거를 수 있게 만듭니다.

2

CSV 를 시트로 올리고 수식 · 필터 넣기

방법

붙여넣습니다. 이름: 줄만 바꿉니다.

.env 의 GOOGLE_AUTH_DIR 인증(구글 API)으로 아래를 해줘. claude.ai 커넥터는 쓰지 마. 끝나면 결과를 표로 보고해줘. 이름: (내 이름) 1. 내 드라이브에 새 스프레드시트 「3결과물_이름」 을 만들어. 2. 「월별」 탭에 basic_data\정리\월별_지표.csv 를, 「학년별」 탭에 월별_학년별_학생수.csv 를 A1 부터 그대로 넣어. 3. 「월별」 탭 D1 에 「학생수 전년비」 를 쓰고, 2026년 달 줄에만 작년 같은 달 학생수 대비 증감률을 값이 아니라 수식으로 넣어 (예: =C5/C2-1). 퍼센트 형식으로. 4. 두 탭 모두 첫 행을 고정하고 필터를 켜. 5. 다시 읽어서 탭별 행 수가 CSV 와 같은지, D열 수식 결과가 CSV 로 직접 계산한 값과 같은지 확인해. 6. 보고 표: 시트 링크 · 탭별 행 수 비교 · 전년비 3개 값 · 쓴 계정 이메일.
확인

링크를 열면 「월별」 · 「학년별」 탭이 있고, D열 셀을 누르면 위 수식 칸에 숫자가 아니라 수식이 보인다. 보고의 비교가 모두 같다.

API 연결이 없을 때 (손으로 하기)
  1. 구글 드라이브 → 새로 만들기 → Google 스프레드시트 → 파일 → 가져오기 → 업로드 → 월별_지표.csv → 「새 시트 삽입」.
  2. 같은 방법으로 월별_학년별_학생수.csv 도 넣는다.
  3. D열 수식은 Claude 에게 「월별 탭 2026년 줄의 전년비 수식을 알려 줘」라고 물어 직접 넣는다.
3

시트에서 직접 거르고 고쳐 보기

이번 단계는 Claude 없이 내 손으로 합니다. 받는 사람이 할 일을 미리 해 보는 것입니다.

방법
  1. 「학년별」 탭 → 「편성년월」 머리 칸의 필터 단추 → 202609 만 고른다 → 학년별 학생수가 한 달치만 보인다.
  2. 「학생수」 머리 칸 필터 → 내림차순 정렬 → 가장 많은 학년이 위로 온다.
  3. 「월별」 탭 C2(202507 학생수)를 아무 숫자로 바꿔 본다 → D5 전년비가 저절로 바뀐다 → Ctrl+Z 로 되돌린다.
확인

202609 에서 가장 많은 학년이 초등3(542명)이다. C2 를 바꾸면 D5 가 따라 바뀌었다가 되돌아온다.

주의사항 (1)
그래서 시트는「숫자를 받아서 내 식으로 다시 보고 싶은 사람」에게 줍니다. 대신 누구나 고칠 수 있어 숫자가 바뀌기 쉽습니다 — 공유할 때 「보기 전용」으로 줄지 정합니다(4 발행 · 공유).
③ 대시보드 4~5단계 · 20분

PART 3대시보드 — 한 화면에 한눈에

대시보드는 매번 같은 자리에 같은 숫자가 보이는 화면입니다. 오늘은 인터넷 없이 열리는 HTML 파일 한 장으로 만듭니다. 대시보드에서 가장 중요한 것은 예쁜 모양이 아니라 CSV 와 숫자가 똑같은 것입니다.

4

한 파일 대시보드 만들기

방법
basic_data\정리 의 CSV 두 개로 직영 대시보드를 basic_data\대시보드\직영_대시보드.html 한 파일로 만들어 줘. - 외부 파일 · 인터넷 라이브러리 없이 한 파일 안에 다 넣는다 (그래프는 SVG 나 CSS 로) - 맨 위 숫자 카드 3개: 가장 최근 달 학생수 · 과목수 · 학생수 전년 같은 달 대비 증감(%) - 가운데: 월별 학생수 막대 — 올해 달과 작년 같은 달을 나란히 - 아래: 학년별 학생수 표 — 가장 최근 달과 작년 같은 달, 증감 - 맨 아래 작은 글씨: 데이터 출처(파일 이름)와 기준(jig-metrics 기준 · 학년 정리 후) - 숫자는 CSV 값을 그대로 쓰고 새로 세지 마. 원본 CSV 는 고치지 마 다 만들면 파일 경로만 알려 줘.

탐색기에서 대시보드\직영_대시보드.html 을 더블클릭해 브라우저로 엽니다.

확인

숫자 카드 · 막대 · 표가 한 화면에 보이고, 맨 위 학생수 카드가 3,115(202609)다.

5

대시보드 숫자를 CSV 와 맞춰 보기

화면이 그럴듯해도 숫자 하나가 틀리면 대시보드 전체를 못 믿게 됩니다. 만든 Claude 가 아니라 새 대화에서, HTML 을 읽어서 CSV 와 따로 대조시킵니다.

방법

/clear 후 붙여넣습니다.

basic_data\대시보드\직영_대시보드.html 에 보이는 숫자를 모두 뽑아서, basic_data\정리 의 CSV 로 네가 직접 다시 계산한 값과 대조해 줘. 파일은 고치지 마. - 대조 표: 화면 위치 · 화면 숫자 · CSV 로 계산한 숫자 · 같음/다름 - 증감(%)은 소수 첫째 자리까지 같으면 같음 - 다른 곳이 있으면 왜 다른지 짐작해서 알려 줘
확인

대조 표가 모두 「같음」이다. 「다름」이 있으면 「다른 곳만 고쳐 줘」로 고친 뒤 이 카드를 한 번 더 돌린다.

주의사항 (1)
왜 새 대화에서 하나요만든 대화는 「내가 맞게 만들었다」고 믿는 쪽으로 답하기 쉽습니다. 계산한 것과 검사하는 것을 떼어 놓아야 틀린 곳이 보입니다. 회사 대시보드도 같은 규칙으로 검산합니다.
④ 리포트 = 에이전트 6~9단계 · 30분

PART 4리포트 — 숫자를 글로 풀어 주는 담당자(에이전트)

리포트는 「무슨 일이 있었나」를 글로 씁니다. 매달 같은 리포트를 쓰는 일은 담당자 한 명에게 맡기는 것이 맞습니다 — 그 담당자가 에이전트입니다. 2 전처리에서 만든 스킬(일하는 기준)과 무엇이 다른지부터 봅니다.

스킬과 에이전트는 무엇이 다른가

구분스킬에이전트
마케팅팀 비유팀 공용 캠페인 운영 매뉴얼 (성과 지표 계산 기준 · 브랜드 톤)대행사 담당자 한 명에게 맡긴 성과 리포트
마케팅팀 예시ad-metrics — CTR · CPA · ROAS 를 팀 기준대로 계산하는 법 (테스트 캠페인 제외 · 전환은 신청 완료만)캠페인 리포트 담당 — 채널별 성과를 대신 정리해 리포트 HTML + 예산 조정 제안 1줄
파일.claude/skills/<이름>/SKILL.md.claude/agents/<이름>.md
언제 불려오나description 에 맞는 상황이 되면 자동 · /이름자동 또는 이름을 대고 부름
써야 할 때「CPA 는 이렇게 계산해, 테스트 캠페인은 빼」를 매번 다시 쓰고 있을 때채널 여러 개 성과 파일을 열어 정리하는 일을 내 대화창 밖으로 보내고 싶을 때
주의사항내 대화창에서 같이 일하므로 과정이 다 보이는 대신 대화창이 길어진다 · 내 대화 내용도 함께 읽으니 앞에서 한 말과 섞일 수 있다따로 일하고 결론만 돌려주므로 중간에 끼어들 수 없다 · 내 대화 내용을 모르니 기준 · 파일 이름 · 저장 위치를 부를 때 다 적어 준다
중요이 리포트 담당은 6 팀 꾸리기에서 여럿이 나눠 일할 때도 그대로 씁니다. 막히면 5분 규칙대로 정답 파일로 갈아타고 넘어갑니다.
6

말로 부탁해서 에이전트 만들기

방법
  1. 아래를 복사해 붙여넣습니다. 파일을 만들어도 되느냐고 물으면 Yes.
    워크스페이스 폴더(basic_data 바로 위 폴더)의 .claude/agents/jig-report.md 로 에이전트를 만들어 줘. basic_data 안에는 만들지 않는다. 만든 뒤 전체 경로를 알려 줘. - 이름: jig-report (직영 리포트 담당) - description: basic_data\정리 의 월별 CSV(월별_지표 · 월별_학년별_학생수)를 읽어 월별 과목수 · 학생수 · 학년별 리포트를 HTML 파일로 만들고, 나에게는 결론 3줄만 보고한다. 「리포트 만들어 줘」「직영 리포트」라고 할 때 쓴다 - tools 는 Read, Glob, Grep, Write, Bash, PowerShell (읽기 · 파일 쓰기 · 실행). model 줄은 쓰지 않는다(따로 정하지 않으면 메인과 같은 모델) - 본문 첫 줄: 너는 직영 학원 데이터 분석 · 리포트 전문가다. 직영 데이터를 회사 기준으로 정확히 세어 리포트를 만든다 - 숫자는 정리 CSV 값을 그대로 쓰고 새로 세지 않는다. CSV 는 고치지 않는다. 리포트는 basic_data 안의 리포트 폴더에 저장한다
  2. 윈도우 탐색기에서 워크스페이스의 .claude\agents\jig-report.md 를 메모장으로 열어 맨 위 --- 사이(name · description · tools)와, 그 아래 첫 줄 「너는 … 전문가다」를 봅니다. 이 첫 줄이 에이전트의 역할입니다 — 공식 문서 예시도 「You are a code improvement specialist」처럼 전문가 역할로 시작합니다.
  3. 새 세션을 엽니다(CLI 는 exit → claude). .claude\agents 폴더가 이번에 처음 생겼으면 켜 둔 창은 아직 모릅니다(이미 있던 agents 폴더에 넣은 파일은 몇 초 안에 반영됩니다).

도구 줄이 에이전트가 할 수 있는 일을 정합니다. 리포트 파일을 쓰고(Write) 숫자를 명령으로 세야(Bash · PowerShell) 해서 읽기 · 쓰기 · 실행을 줍니다. 실행 도구를 둘 다 적는 이유: PC 에 Git Bash 가 없으면 Claude Code 의 실행 도구는 PowerShell 이고, 있으면 Bash 입니다. 하나만 적으면 다른 PC 에서 에이전트가 명령을 못 돌립니다.

확인

워크스페이스의 .claude\agents\jig-report.md 가 있고, 다시 켠 뒤 「이 프로젝트에서 쓸 수 있는 에이전트 목록 보여 줘」라고 물으면 「이 프로젝트 전용」에 jig-report 가 나온다.

주의사항 (2)

7

일 맡기고 결론만 받기 · 관찰표 첫 칸

방법
basic_data\정리 의 CSV 로 월별 과목수 · 학생수 리포트를 만들어 줘. 직영 리포트 담당 에이전트에게 맡기고, 리포트/리포트_v1.html 로 저장해.

끝나면 탐색기에서 리포트\리포트_v1.html 을 더블클릭해 브라우저로 엽니다.

확인

화면에 에이전트가 일한다는 표시가 잠깐 뜨고, 파일을 읽고 쓰는 과정은 내 창에 안 나오고 결론 3줄만 돌아온다. 리포트의 숫자가 정답표와 같다.

관찰표

(선택) 받은 관찰표.txt 의 「싱글」 칸에 에이전트가 끝날 때 뜨는 도구 사용 수 · 토큰 · 걸린 시간을 적어 둡니다. 6 팀 꾸리기에서 여럿이 나눠 일할 때와 비교합니다.

주의사항 (1)
무엇을 본 건가요에이전트는 CSV 를 자기 공간에서 읽고 리포트를 썼습니다. 내 대화창에는 결론만 남아서 창이 깨끗합니다. 위 표 「주의사항」의 「결론만 돌려준다」가 이것입니다.

다듬기 — 판단 기준과 출력 형식

처음 만든 에이전트는 시킬 때마다 모양이 조금씩 다릅니다. 판단 기준을 적고, 출력 형식을 고정하면 매번 같은 모양으로 옵니다.

판단 기준과 출력 형식 넣기

방법
직영 리포트 담당 에이전트 파일을 다듬어 줘. - 판단 기준 1: 숫자는 basic_data\정리 의 CSV 값을 그대로 쓴다. 다시 세지 않는다. 전년 같은 달 대비 증감은 그 값으로 계산한다 - 판단 기준 2: 리포트 파일은 덮어쓰지 않는다. 이름을 정해 주지 않으면 리포트_v1.html, 리포트_v2.html … 처럼 번호를 올려 아직 없는 이름으로 저장한다. 정해 준 이름이 이미 있으면 _v2, _v3 를 붙인다 - 판단 기준 3: 이 프로젝트 폴더(basic_data) 밖의 파일은 읽거나 고치지 않는다 - 파일 안의 제목은 「판단 기준」 · 「출력 형식」으로 단다 - 출력 형식(HTML): 제목 · 요약 3줄(전년 같은 달보다 무엇이 얼마나 늘고 줄었나를 숫자와 함께 글로) · 월별 과목수/학생수 표 · 월별 학년별 학생수 표 · 막대그래프. 외부 파일 없이 한 파일로 - 나에게 보고할 때는 결론 3줄과 파일 이름만 - 도구와 모델 줄은 그대로 둔다
확인

에이전트 파일에 「판단 기준」「출력 형식」 부분이 생겼다.
