시작 전초급에서 만든 리포트 담당을 정식 직원으로 채용합니다

초급 교육 편에서 만든 직영 리포트 담당 에이전트는 내가 대화창에서 부를 때만 일했습니다. 오늘은 이 담당을 AI 직원으로 채용해, 내 PC 가 켜져 있는 동안 정해진 시각에 혼자 출근해서 리포트를 만들고 슬랙으로 보고하게 만듭니다. 내가 자리에 없어도 일이 끝나 있는 상태가 목표입니다.

끝나면 이렇게 됩니다
  • 대화창을 열지 않아도 claude -p 한 줄로 일을 시키고 끝나는 것을 봤다.
  • 작업 스케줄러에 출근표를 등록했고, 내가 아무것도 안 했는데 2분 뒤 리포트가 생기고 슬랙에 보고가 왔다.
  • AI 직원이 고친 것을 Git 으로 남기고, 틀린 결과를 되돌려 봤다. 멈추거나 실패해도 「실패」 보고가 온다.
  • 검산 담당을 붙여 작성자와 검산자를 나눴고, 사람이 지켜볼 때만 쓰는 에이전트 팀까지 비교했다.

PART 1보기 · 준비 · 채용 (1~3단계)

1

생각 열기 — 이미 일하는 AI 직원 보기

방법

강사가 자기 PC 의 작업 스케줄러를 열어, 매일 정해진 시각에 혼자 도는 작업들을 보여 줍니다. 세 가지만 봅니다.

  • 이름과 시각 — 평일 아침 · 저녁마다 리포트 · 판정을 만드는 작업이 여럿 등록돼 있다.
  • 마지막 실행 결과 — 사람이 누르지 않았는데 오늘 아침에 이미 돌았다.
  • 슬랙 — 끝나면 결론 몇 줄이 메시지로 와 있다. 사람은 그 메시지만 읽는다.
확인

「AI 직원 = 업무 지시서 + 출근표 + 보고」를 말할 수 있다.

2

교육 편 폴더 열고 리포트 담당 · 보고 주소 확인

방법
  1. VS Code(또는 Cursor)에서 [파일] → [폴더 열기] → 초급 교육 편의 basic_data.
  2. 탐색기에서 .claude/agents/jig-report.md 와 .claude/skills/jig-metrics/SKILL.md 가 있는지 봅니다.
  3. basic_data 바로 아래 .env 파일을 열어 슬랙 웹훅 주소가 한 줄 있는지 봅니다. 없으면 파일을 만들고 Advance 교육 편에서 만든 주소(또는 강사가 알려 준 교육용 주소)를 이렇게 적습니다.
    SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...

    주소는 채팅창에 붙이지 않고 파일에 직접 씁니다. 이 주소를 아는 사람은 누구나 그 채널에 글을 쓸 수 있습니다.

  4. 터미널에서 claude 를 켭니다.
확인

에이전트 · 스킬 파일이 있고, .env 에 SLACK_WEBHOOK_URL= 줄이 있다.

없으면받은 정답_리포트담당.md 를 basic_data\.claude\agents\jig-report.md 로, 정답_jig-metrics 폴더를 basic_data\.claude\skills\jig-metrics 로 넣은 뒤 exit → claude. 웹훅 주소가 아직 없으면 줄은 비워 두고 진행합니다 — 6단계에서 「보고 생략」으로 넘어갑니다.
3

채용 — 업무 지시서와 출입증

사람 없이 도는 직원에게는 되묻지 않아도 되는 지시서와 들어가도 되는 곳만 열리는 출입증이 필요합니다. 대화창에서는 Claude 가 모르면 물어보고, 위험한 일은 허락을 구했습니다. 출근표로 돌 때는 물어볼 사람이 없습니다.

방법
AI 직원을 한 명 채용하려고 해. 이 폴더 안에 ai_staff 폴더를 만들고 아래 두 파일을 써 줘. 아직 아무것도 실행하지 마. 1) ai_staff/업무지시서.md — AI 직원이 혼자 읽고 끝까지 할 수 있게 쓴다. - 직영 리포트 담당(jig-report) 에이전트에게 직영_실습데이터.csv 로 가장 최근 편성년월의 과목수 · 학생수 리포트를 만들게 한다 - 리포트는 리포트/자동_오늘날짜(YYYYMMDD).html 로 저장한다. 같은 이름이 있으면 _v2, _v3 를 붙인다 - 계산용 임시 파일은 ai_staff/작업/ 에만 둔다 - 마지막 답은 결론 3줄 + 파일 이름만 쓴다 - 사람에게 질문하지 않는다. 막히면 「확인 필요: 이유」 한 줄로 끝낸다 2) ai_staff/출입증.txt — 사람 없이 돌 때 허용할 도구 목록. 아래 한 줄만 그대로 쓴다. Read,Glob,Grep,Agent,Edit(./리포트/**),Edit(./ai_staff/작업/**),Bash(node:*),PowerShell(node:*)
확인

ai_staff 폴더에 업무지시서.md · 출입증.txt 두 파일이 생겼고, 리포트는 아직 안 생겼다(실행하지 말랬으니).

출입증을 읽는 법Read · Glob · Grep = 읽고 찾기 · Agent = 리포트 담당 부르기 · Edit(./리포트/**) = 리포트 폴더에만 만들고 고치기 · Edit(./ai_staff/작업/**) = 계산용 임시 폴더 · Bash(node:*) · PowerShell(node:*) = node 로 시작하는 명령만. 여기 없는 일(다른 폴더 쓰기 · 파일 지우기 · 다른 명령)은 물어볼 사람이 없으니 거절된 채로 넘어갑니다. 폴더를 정해 주는 칸은 Write(...) 가 아니라 Edit(...) 로 씁니다 — Write(./리포트/**) 로 쓰면 리포트 폴더 쓰기까지 거절됩니다(실측).
보안은 master 과정에서오늘 출입증은 「리포트 폴더 쓰기 · node 명령」만 여는 최소한입니다. 무인 실행의 권한 · 규칙을 제대로 설계하는 것은 master 교육에서 다룹니다.

PART 2출근과 보고 (4~6단계)

4

첫 출근 — 옆에서 지켜보며 한 번

방법
  1. 대화창 없이 시켜 보기 — 오른쪽 터미널(새로 연 창, basic_data 위치)에 붙여넣습니다.
    claude -p "이 폴더에 있는 파일과 폴더 이름을 한 줄로 알려 줘"

    답 한 줄이 나오고 바로 끝납니다. 대화창이 열리지 않습니다. 이것이 AI 직원이 일하는 방식입니다 — 한 번 시키고, 끝나면 나간다.

  2. 출근 스크립트 만들기 — 왼쪽 Claude Code 에 붙여넣습니다.
    출근 스크립트 ai_staff/run.js 를 만들어 줘. Node 기본 기능만 쓰고(추가 설치 없음), 만든 뒤 실행하지는 마. - 이 폴더를 작업 위치로 claude -p 를 실행한다. 프롬프트는 ai_staff/업무지시서.md 내용을 표준입력으로 넣는다 - 허용 도구는 ai_staff/출입증.txt 의 한 줄을 --allowedTools 로 넘긴다 - 커넥터는 띄우지 않는다: --strict-mcp-config --mcp-config ai_staff/empty_mcp.json (빈 설정 {"mcpServers":{}} 파일이 없으면 만든다) - Claude 의 출력은 파이프가 아니라 파일로 받고, 창은 숨긴다(windowsHide) - 실행마다 ai_staff/출근기록/YYYY-MM-DD_HHMM.txt 에 시작 시각 · 끝 시각 · 끝 코드 · Claude 의 마지막 답을 남긴다
  3. 첫 출근 — 오른쪽 터미널에서 직접 출근시킵니다. 끝날 때까지 몇 분 걸립니다.
    node ai_staff/run.js
확인

리포트 폴더에 자동_오늘날짜.html 이 생겼고, ai_staff\출근기록\ 에 시작 · 끝 시각과 결론 3줄이 적힌 파일이 생겼다. 리포트의 202609 과목수 · 학생수가 정답표 [1] 과 같다.

왜 스크립트로 감싸나요claude -p 한 줄로도 일은 됩니다. 하지만 출근표(5단계)는 창 없이 · 사람 없이 돕니다. 출입증을 붙이고, 커넥터 로그인 창을 기다리다 멈추지 않게 하고, 무슨 일이 있었는지 출근기록에 남기는 일을 run.js 가 맡습니다. 6 · 7 · 8단계는 이 파일에 보고 · 근무일지 · 결근 대비를 하나씩 더 붙입니다.
5

출근표 — 작업 스케줄러에 등록

방법
  1. 왼쪽 Claude Code 에 붙여넣습니다.
    ai_staff/run.js 를 윈도우 작업 스케줄러에 등록해 줘. 내 계정으로, 관리자 권한 없이 PowerShell 의 Register-ScheduledTask 로 한다. - AI직원_리포트: 평일(월~금) 09:00 - AI직원_리포트_시험: 지금부터 2분 뒤 한 번만 - 둘 다 실행 = node 전체 경로 + run.js 전체 경로, 시작 위치 = 이 폴더 - 둘 다 「예약된 시작 시간을 놓치면 가능한 빨리 실행」(StartWhenAvailable) 을 켠다 등록한 뒤 두 작업의 다음 실행 시각을 보여 줘.
  2. 2분 동안 아무것도 하지 않고 기다립니다. 시각이 되면 검은 창이 하나 뜹니다 — AI 직원이 출근한 것입니다. 그 창을 닫지 마세요(닫으면 그날 일을 하다 퇴근합니다).
  3. 윈도우 검색에서 작업 스케줄러를 열고 작업 스케줄러 라이브러리에서 두 작업을 찾아 봅니다. 「다음 실행 시간」 「마지막 실행 결과」 칸을 봅니다.
확인

내가 아무것도 누르지 않았는데 출근기록 에 새 파일이 생겼다. 작업 스케줄러에 AI직원_리포트(평일 09:00) · AI직원_리포트_시험 두 작업이 보인다.

「예정 시간을 놓치면 가능할 때 바로 실행」09:00 에 PC 가 꺼져 있었다면, 켠 뒤 곧바로 그날 출근을 합니다. 이 옵션이 없으면 그날은 건너뜁니다. 작업 속성의 [설정] 탭에서 이 칸이 체크돼 있는지 봅니다.
주의출근표는 내 계정으로 로그인한 동안만 돕니다. 잠금 화면이어도 로그인돼 있으면 돌지만, 로그아웃 · 종료 상태에서는 돌지 않습니다.
6

보고 — 끝나면 슬랙으로

사람이 화면 앞에 없으니, 일이 끝났다는 것을 알려 줘야 합니다. Advance 교육 편에서 만든 슬랙 웹훅을 AI 직원에게 연결합니다.

방법
run.js 에 보고를 붙여 줘. 일이 끝나면 이 폴더 .env 의 SLACK_WEBHOOK_URL 로 슬랙에 보낸다. Node 기본 기능만 쓰고, 실행하지는 마. - 내용: 첫 줄 「[AI직원] 직영 리포트 완료」, 그 아래 Claude 의 마지막 답 - 웹훅 주소는 코드 · 출근기록 어디에도 적지 않는다 (.env 에서 읽기만) - SLACK_WEBHOOK_URL 이 비어 있거나 없으면 보내지 않고 출근기록에 「보고: 생략(주소 없음)」, 보냈으면 「보고: 보냄」, 보내다 실패하면 「보고: 실패」

근무일지 — 고친 것은 Git 으로

출근기록은 「언제 왔다 갔나」, Git 은 「무엇을 바꿨나」입니다. 사람이 안 보는 사이에 바뀐 파일은 Git 에 남아 있어야 비교하고 되돌릴 수 있습니다.

방법
  1. 왼쪽 Claude Code 에 붙여넣습니다.
    run.js 에 근무일지를 Git 으로 남기는 기능을 붙여 줘. run.js 는 실행하지 마. - 먼저 지금 한 번: 이 폴더가 Git 저장소가 아니면 git init 하고, .gitignore 에 .env · 직영_실습데이터.csv · ai_staff/출근기록/ · ai_staff/작업/ 를 넣는다. 커밋할 사람 이름이 설정돼 있지 않으면 이 저장소에만 user.name 「AI직원」 · user.email 「ai-staff@local」 로 정한다 - run.js: 일이 성공하면(끝 코드 0) 리포트 폴더만 git add 하고 「AI직원 리포트 YYYY-MM-DD」 메시지로 커밋한다. 바뀐 게 없으면 커밋하지 않는다 - git 이 없으면 커밋하지 않고 출근기록에 「근무일지: Git 없음」 - push 는 하지 않는다
  2. 오른쪽 터미널에서 한 번 더 출근시킵니다(6단계 보고도 같이 확인).
    node ai_staff/run.js
  3. 실수 되돌리기 — 왼쪽에 차례로 붙여넣습니다.
    리포트 폴더의 가장 최근 자동 리포트에서 제목 글자를 「망가진 리포트」로 바꿔 줘.
    Git 으로 마지막 근무일지 이후 무엇이 바뀌었는지 보여 주고, 그 파일을 마지막 근무일지 상태로 되돌려 줘.
확인

  3. 끄기 — 붙여넣은 뒤 exit → claude.
