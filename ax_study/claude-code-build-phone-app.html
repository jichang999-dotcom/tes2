PART 0시작 전

체험A 에서 웹으로 만든 출퇴근 앱을 이번에는 휴대폰에 설치하는 앱(React Native · Expo)으로 만듭니다. 만든 앱은 Expo Go 라는 앱 안에서 바로 열어 봅니다. 각 단계 오른쪽 위 완료를 체크하면 위쪽 막대에 진행률이 표시됩니다.

오늘의 주제주제는 출퇴근이 아니라 「사내 앱을 말로 만든다」입니다. 체험A(웹)와 체험B(폰 앱) 중 하나를 골라 만듭니다. 두 과정의 미션은 같습니다.
끝나면 이렇게 됩니다
  • 진행자가 띄운 QR 로 완성본 폰 앱에서 출근을 찍어 봤다.
  • 글 한 장으로 내 폰 앱을 만들고, 내 휴대폰에서 GPS 로 출근을 찍었다.
  • 말로 고치면 휴대폰 화면이 저절로 바뀌는 것을 봤다.
  • 내 Supabase(클라우드 데이터베이스)를 만들고, 폰에서 누른 출근이 서버 테이블에 쌓이게 연결했다.

PART 1완성본 폰 앱 써 보기 (1~3단계)

체험A 의 출퇴근 앱을 폰 앱으로 옮긴 완성본입니다. 진행자 노트북에서 돌고 있고, QR 로 내 휴대폰에서 엽니다.

1

Expo Go 설치

방법
  1. 안드로이드 = Play 스토어, 아이폰 = App Store 에서 Expo Go 검색 → 설치 (이미 있으면 업데이트)
  2. 설치한 Expo Go 를 한 번 엽니다. 로그인은 하지 않아도 됩니다.
확인

Expo Go 첫 화면이 열린다.

아이폰「Expo Go 가 로컬 네트워크의 기기를 찾으려고 합니다」 창이 뜨면 반드시 허용. 거부하면 QR 을 찍어도 계속 돌다 타임아웃이 납니다. 이미 거부했다면 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → Expo Go 켜기.
2

진행자 QR 찍기

방법

진행자 화면의 QR 을 찍습니다.

안드로이드Expo Go 앱 → [Scan QR code] → QR 찍기
아이폰기본 카메라 앱으로 QR 찍기 → 위에 뜨는 「Expo Go 에서 열기」

처음엔 내려받느라 10~30초 걸립니다.

확인

날짜 · 흐르는 시계 · 초록 [출근] · 파란 [퇴근] 이 있는 화면이 휴대폰에 뜬다.

왜 QR 이 가이드에 없나요?이 QR 은 진행자 노트북이 켜져 있는 동안만 쓰는 주소라 매번 바뀝니다. 그래서 교육 때 진행자 화면에 띄웁니다.
3

출근 찍기

방법

[출근] → 위치 권한을 물으면 앱을 사용하는 동안 허용.

확인

회사 안이면 「출근 09:xx」 와 표에 오늘 줄. 밖이면 「반경 밖이에요 (회사에서 ○○m)」. 이제 휴대폰 GPS 로 판정한 것입니다.

알아 두기규칙은 체험A 완성본과 같습니다 — 반경 100m, 건물 안 GPS 오차를 봐주는 「거리 − 오차 ≤ 100m」. 안드로이드에서는 가짜 위치 앱이 켜져 있으면 거부합니다. 웹으로는 못 하던 일입니다.

PART 2내 폰 앱 만들기 (4~7단계)

같은 앱을 내 노트북에서 만듭니다. 글을 직접 치지 않고 카드를 복사해 붙여넣습니다. 설치가 끼어 있어 체험A 보다 조금 오래 걸립니다.

4

작업 폴더에서 Claude Code 켜기

방법
  1. 입문 과정에서 만든 작업 폴더(예: claude_work)를 VS Code(또는 Cursor)로 엽니다.
  2. 터미널에서 claude 입력 → Enter

새 폴더는 만들지 않습니다. 다음 단계의 카드가 작업 폴더 안에 app_expo 폴더를 만들어 줍니다.

확인

Claude Code 입력창이 뜨고, 위쪽에 작업 폴더 경로가 보인다.

5

만들기 카드 붙여넣기

방법

[복사] → Claude Code 입력창 클릭 → Ctrl + V → Enter. 3~5분 걸립니다(앱 뼈대를 내려받습니다).

지금 작업 폴더 안에 app_expo 라는 Expo 앱을 새로 만들어 줘. - 만들기: npx create-expo-app@latest app_expo --template blank - 모듈: app_expo 안에서 npx expo install expo-location @react-native-async-storage/async-storage App.js 에 출퇴근 화면을 만들어 줘. - 오늘 날짜와 지금 시각(초가 흐르게) - 큰 [출근] [퇴근] 버튼 - 누르면 폰 위치를 받아 회사 좌표(37.47381, 126.99494)에서 몇 m 인지 보여 주고, 100m 안이면 기록, 밖이면 "반경 밖" - [테스트 모드] 스위치: 켜면 회사에 있는 것으로 친다 - 기록은 아래 표(날짜 · 출근 · 퇴근)에 쌓이고 앱을 껐다 켜도 남게. 09:30 넘은 출근은 빨간 글씨 - 맨 위 한 줄에 지금 설정(반경, 기준 시각 09:30) - 연습용 [기록 지우기] 버튼 서버나 로그인은 넣지 마. npx expo start 는 실행하지 마(내가 따로 켠다). app_expo 안의 CLAUDE.md(만들 때 같이 생긴다)는 원래 있던 줄을 그대로 두고 아래에 이 앱 설명을 덧붙여 줘: 이 앱이 무엇인지, 지금 설정(회사 좌표 · 반경 · 기준 시각), 기록이 어디에 저장되는지를 짧게 적고, 앱 코드를 고치면 CLAUDE.md 의 설정도 같이 고치라고 적어 줘. 작업 폴더에 원래 있던 CLAUDE.md 는 건드리지 않는다. 끝나면 npx expo-doctor 로 점검하고, 폰으로 여는 방법을 세 줄로 알려 줘.

명령을 실행해도 되는지 물으면 Yes 를 고릅니다.

확인

왼쪽 탐색기에 app_expo 폴더와 그 안의 App.js · CLAUDE.md 가 생기고, 마지막에 「폰으로 여는 방법」 세 줄이 나온다.

CLAUDE.md 는 왜 만드나요?이 앱의 설명서입니다. 앱이 무엇인지, 지금 설정(반경 · 기준 시각)이 무엇인지 적혀 있어서, 다음에 Claude Code 가 이 폴더를 고칠 때 먼저 읽고 시작합니다. 미션으로 반경을 바꾸면 설명서의 반경도 같이 바뀝니다. 맨 위 @AGENTS.md 한 줄은 Expo 가 넣어 둔 것이라 그대로 둡니다. 입문에서 만든 작업 폴더의 CLAUDE.md 도 그대로입니다.
5분 규칙app_expo 는 생겼는데 끝나지 않거나 화면이 이상하면, 받은 정답 폴더의 App.js · logic.js 두 파일을 app_expo 에 덮어쓰고 6단계로. app_expo 자체가 안 생기면(설치 실패) 체험A(웹)로 옮깁니다.
정답 파일로 갈아탔다면 — 설명서 카드

정답 파일에는 앱 설명서(CLAUDE.md)가 없습니다. 이 카드를 붙여넣으면 만들어 줍니다. 없어도 미션은 됩니다.

app_expo 의 App.js · logic.js 를 읽고, app_expo 안의 CLAUDE.md 는 원래 있던 줄을 그대로 두고 아래에 이 앱 설명을 덧붙여 줘: 이 앱이 무엇인지, 지금 설정(회사 좌표 · 반경 · 기준 시각), 기록이 어디에 저장되는지를 짧게 적고, 앱 코드를 고치면 CLAUDE.md 의 설정도 같이 고치라고 적어 줘. 앱 코드는 고치지 않는다. 작업 폴더에 원래 있던 CLAUDE.md 는 건드리지 않는다.
6

새 터미널에서 앱 서버 켜기

방법
  1. VS Code 메뉴 [터미널] > [새 터미널] — Claude Code 가 도는 터미널은 그대로 두고 하나 더 엽니다.
  2. 아래 두 줄을 한 줄씩 붙여넣고 Enter
    cd app_expo npx expo start
  3. 「Windows 방화벽」 창이 뜨면 [허용]
확인

터미널에 네모난 QR 코드와 exp:// 로 시작하는 주소가 보인다.

왜 Claude 에게 안 시키나요?npx expo start 는 끄기 전까지 계속 도는 명령입니다. Claude Code 안에서 돌리면 QR 이 안 보이거나 대화가 멈춥니다. 그래서 이것만 직접 칩니다.
7

내 QR 찍고 출근

방법

2단계와 같은 방법으로 내 터미널의 QR 을 찍습니다 → [출근] (실내라 「반경 밖」이면 [테스트 모드] 를 켜고 다시).

확인

휴대폰에 내가 만든 출퇴근 앱이 뜨고, 표에 오늘 줄이 생긴다. Expo Go 를 닫았다 다시 열어도 남아 있다.

계속 돌다 타임아웃① 아이폰 로컬 네트워크 허용(1단계) ② 휴대폰이 노트북과 같은 Wi-Fi 인지 ③ 그래도 안 되면 터미널에서 Ctrl + C 로 끄고 npx expo start --tunnel (추가 설치를 물으면 y). 회사 Wi-Fi 는 기기끼리 통신을 막는 경우가 많아 ③ 이 필요할 수 있습니다.
② 말로 고치기 8~9단계 · 15분

PART 3말로 고치기 (8~9단계)

미션에는 원하는 것만 적혀 있습니다. Claude Code 가 도는 터미널에서 자기 말로 시킵니다. 파일이 저장되면 휴대폰 화면이 저절로 바뀝니다(Hot Reload). 새로고침할 필요가 없습니다.

요령6단계에서 켠 앱 서버 터미널은 끄지 않습니다. 휴대폰 화면이 안 바뀌면 휴대폰을 흔들어 나오는 메뉴에서 Reload.

원하는 것

예시 문장 보기
회사 반경을 100m에서 300m로 넓혀 줘
확인

휴대폰 화면 맨 위 설정 줄이 저절로 300m 로 바뀐다.

미션 2 — 퇴근하면 일한 시간 보이게

원하는 것

퇴근을 누르면 그날 일한 시간이 표에 보이면 좋겠다.

예시 문장 보기
퇴근을 누르면 그날 일한 시간(몇 시간 몇 분)이 기록 표에 보이게 해 줘
확인

[퇴근] → 표에 「몇 시간 몇 분」. 7단계에서 찍은 출근 시각부터 지금까지 시간이 나옵니다. 기록을 지웠다면 [출근] 부터.

③ 백엔드 붙이기 10~13단계 · 20분

PART 4Supabase 로 백엔드 붙이기 (10~13단계)

지금 기록은 내 휴대폰 안(앱 저장소)에만 있습니다. 앱을 지우거나 폰을 바꾸면 사라지고, 다른 사람과 모을 수 없습니다. 이제 Supabase 에 테이블을 만들고 앱이 기록을 서버로 보내게 합니다. Supabase 는 데이터베이스(Postgres)와 그 앞의 API 를 한 번에 빌려 주는 서비스라 서버 코드를 따로 쓰지 않아도 됩니다.

폰 앱 (App.js)Supabase APIattendance 테이블 (DB)
[출근] 을 누르면 기록 한 줄을 보낸다→
주소 + 공개 키		보안 규칙(RLS)을 확인하고 받는다→날짜 · 출근 · 퇴근이 쌓인다
누가 무엇을 하나SQL 과 앱 연결 코드는 Claude Code 가 씁니다. 사람은 가입 · SQL 실행 · 주소와 키 복사 세 가지만 브라우저에서 손으로 합니다. 6단계에서 켠 앱 서버 터미널은 그대로 둡니다.
10

Supabase 가입 · 프로젝트 만들기

방법
  1. 노트북 브라우저에서 supabase.com → [Start your project] → GitHub 로 계속하기(또는 이메일 가입 → 받은 메일의 링크 클릭)
  2. [New project] → Name: commute · Database Password: [Generate a password] · Region: Northeast Asia (Seoul) → [Create new project]
  3. 1~2분 기다립니다(서버를 만드는 중)
확인

왼쪽에 메뉴(Table Editor · SQL Editor …)가 있는 프로젝트 첫 화면이 뜬다.

알아 두기데이터베이스 비밀번호는 오늘 쓰지 않습니다. 무료 플랜은 한동안 쓰지 않으면 프로젝트가 잠시 멈춤 상태가 되고, 대시보드에서 다시 켤 수 있습니다.
11

테이블 카드 붙여넣기

방법

Claude Code 입력창에 [복사] → Ctrl + V → Enter. 1분 안팎 걸립니다.

app_expo 폴더에 supabase.sql 파일을 만들어 줘. Supabase 의 SQL Editor 에 붙여넣어 실행할 SQL 이다. - attendance 테이블: 앱 기록 표의 칸 그대로(날짜 · 출근 · 퇴근 · 거리 등) + 만든 시각. 날짜 · 시각은 글자로(예 2026-09-27, 09:12) - 같은 날짜는 한 줄만 (날짜에 unique) - 행 수준 보안(RLS)을 켜고, 체험용으로 앱의 공개 키(anon)로 읽기 · 추가 · 수정 · 지우기가 되게 정책을 만든다. anon 역할에 테이블 권한(grant)도 준다 - 여러 번 실행해도 오류가 나지 않게 앱 코드는 아직 고치지 않는다. app_expo 의 CLAUDE.md 에 supabase.sql 이 무엇인지 한 줄 추가해 줘. 끝나면 이 SQL 을 Supabase 에서 실행하는 방법을 세 줄로 알려 줘.
확인

app_expo 안에 supabase.sql 이 생기고, 마지막에 「Supabase 에서 실행하는 방법」 세 줄이 나온다.

5분 규칙supabase.sql 이 안 생기면 받은 정답 폴더의 supabase.sql 을 app_expo 에 넣고 12단계로. 13단계 연결 카드는 정답 파일로도 똑같이 됩니다.
RLS 가 뭔가요?행 수준 보안(Row Level Security). 테이블마다 「누가 무엇을 읽고 쓸 수 있나」를 정하는 규칙입니다. 오늘은 체험용이라 앱의 공개 키를 가진 누구나 읽고 쓰게 열어 둡니다. 실제 사내 앱은 로그인한 사람이 자기 줄만 보게 좁힙니다.

SQL 실행하고 주소 · 키 복사

방법
  1. Supabase 왼쪽 메뉴 [SQL Editor] → 새 쿼리 → VS Code 에서 supabase.sql 을 열어 전부 복사해 붙여넣기 → [Run]
  2. 왼쪽 [Table Editor] 에서 attendance 테이블이 생겼는지 봅니다
  3. 화면 위쪽 [Connect] → 모바일(Expo · React Native) 항목에서 EXPO_PUBLIC_SUPABASE_URL=… 로 시작하는 두 줄을 복사합니다. 바로 다음 단계에서 붙여넣습니다
확인

SQL 결과에 Success. Table Editor 에 빈 attendance 테이블.

주의복사할 것은 publishable(또는 anon) 키 — 앱에 넣어도 되는 공개 키입니다. secret(또는 service_role) 키는 앱에 절대 넣지 않습니다. [Connect] 가 안 보이면 Project Settings → API Keys 에서 Project URL 과 publishable 키를 복사해 EXPO_PUBLIC_SUPABASE_URL=주소 · EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY=키 두 줄로 적습니다.
13

앱과 Supabase 연결

방법
  1. 아래 카드 [복사] → Claude Code 입력창에 붙여넣기. 아직 Enter 를 누르지 않습니다.
  2. 12단계에서 복사한 두 줄을 입력창 맨 끝 「주소와 키:」 아래에 붙여넣기 → Enter. 설치가 끼어 있어 2~3분 걸립니다.
  3. 끝나면 앱 서버 터미널(6단계)에서 Ctrl + C → npx expo start -c 로 다시 켭니다. .env 는 켤 때 한 번만 읽기 때문입니다. 휴대폰에서 QR 을 다시 찍거나 흔들어 Reload.
app_expo 를 내 Supabase 에 연결해 줘. 주소와 키 두 줄은 맨 아래에 붙였다. - 두 줄은 app_expo/.env 에 그대로 저장하고, 코드에서는 process.env 로 읽는다 - @supabase/supabase-js 는 app_expo 안에서 npx expo install 로 설치한다 (같이 필요한 모듈이 있으면 같이) - 출근 · 퇴근을 기록할 때 같은 폴더 supabase.sql 의 attendance 테이블에도 저장한다 (같은 날짜면 그 줄을 고친다) - 앱을 켜면 표를 테이블에서 불러온다. 연결이 안 되면 폰에 저장된 기록을 그대로 보여 주고 "Supabase 연결 안 됨" 을 잠깐 보여 준다 - [기록 지우기] 는 테이블 기록도 지운다 - 맨 위 설정 줄에 "Supabase 연결됨" 을 보여 줘 - app_expo 의 CLAUDE.md 에 테이블 칸 구성과 .env 이름을 적어 줘 (키 값은 적지 않는다) npx expo start 는 실행하지 마. 끝나면 npx expo-doctor 로 점검해 줘. 주소와 키:
확인

휴대폰 앱 맨 위에 「Supabase 연결됨」. [테스트 모드] → [출근] 을 누르고 Supabase Table Editor 의 attendance 를 새로고침하면 오늘 줄이 보인다. 앱을 완전히 껐다 켜도 표가 테이블에서 다시 채워진다.

무엇이 달라졌나이제 기록이 휴대폰 밖(Supabase 서버)에 있습니다. 같은 주소와 키를 넣은 앱은 모두 같은 테이블에 씁니다 — 여러 사람이 쓰는 사내 앱은 여기서 시작합니다. 실제로 쓰려면 Supabase 로그인(Auth)과 사람별 보안 규칙을 붙입니다.
