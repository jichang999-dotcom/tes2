입문 과정을 마친 사람이 직영 데이터로 스킬(매번 하는 설명을 묶어 두기)과 에이전트(일을 따로 맡기기)를 직접 만들어 보는 교육입니다. 여기서 만든 폴더 · 스킬 · 에이전트는 체험 편에서 그대로 이어 씁니다. 각 단계 오른쪽 위 완료를 체크하면 위쪽 막대에 진행률이 표시됩니다.

끝나면 이렇게 됩니다
  • 과목수 · 학생수를 회사 기준대로 세는 법을 스킬로 만들었고, 부르지 않아도 「몇 명 다녀?」에 불려온다.
  • 데이터를 대신 세어 리포트 HTML 을 만드는 에이전트를 만들었고, 대화창에는 결론 3줄만 받아 봤다.
  • 에이전트를 다듬어 학년치환까지 된 리포트 v2 를 만들었다.

교육 프로젝트 폴더 만들고 열기

방법
  1. VS Code(또는 Cursor)에서 입문에서 만든 작업 폴더(예: claude_work)를 열고, 터미널에서 claude 를 켭니다.
  2. 받은 직영_실습데이터.csv · 열사전.txt 의 경로를 확인합니다. 윈도우 탐색기에서 파일을 고르고 Ctrl+Shift+C(경로로 복사)를 누르면 경로가 복사됩니다.
  3. 아래를 복사해 두 경로를 내 경로로 바꿔서 보냅니다. 폴더를 만들고 옮기는 명령을 실행해도 되느냐고 물으면 Yes.
    이 폴더 안에 basic_data 폴더를 만들고, 아래 두 파일을 그 안으로 옮겨 줘. 다 옮기면 basic_data 안의 파일 목록을 보여 줘. - C:\Users\User\Desktop\Basic\교육\직영_실습데이터.csv - C:\Users\User\Desktop\Basic\교육\열사전.txt
  4. 목록에 두 파일이 보이면 exit → [파일] → [폴더 열기] → basic_data 를 엽니다.
  5. 터미널에서 claude 입력 → Enter. 폴더 신뢰를 물으면 Yes.
확인

왼쪽 탐색기에 직영_실습데이터.csv 와 열사전.txt 가 보이고, Claude Code 입력창이 떠 있다.

왜 다시 켜나요스킬과 에이전트는 claude 를 켠 폴더의 .claude 에 생깁니다. claude_work 에서 켠 채로 계속하면 엉뚱한 곳에 생깁니다.
열사전.txt 를 한 번 훑어보세요오늘 쓰는 열(학생코드 · COLC · 요일 · 시작시간 · 학년 · 학급수강상태 · 프로그램명)의 뜻이 들어 있습니다. 회사 기준 세는 법 · 학년치환은 일부러 넣지 않았습니다 — 4단계 · 12단계에서 Claude 가 기준 없이 하는 모습을 보려고요. 기준은 5단계 · 13단계 카드에 있습니다.
왜 새 폴더인가요스킬과 에이전트가 이 폴더의 .claude 에 생깁니다. 체험 편에서 이 폴더를 그대로 다시 엽니다.
② 스킬 4~10단계 · 30분

PART 3스킬 만들기

스킬 = 매번 치는 설명과 절차를 묶어 둔 것입니다. 한 번 만들어 두면 같은 설명을 다시 치지 않아도 되고, 그 상황이 오면 Claude 가 알아서 꺼내 씁니다.

순서처음부터 스킬을 설계하지 않습니다. ① 대화로 한 번 세어 보고 → ② 틀린 곳을 고쳐 주고 → ③ 「방금 정한 세는 법을 스킬로」.
4

대화로 먼저 세어 보기

방법

[복사] → Claude Code 입력창에 붙여넣기 → Enter.

직영_실습데이터.csv 에서 202609 의 과목수와 학생수를 세 줘. 파일이 크니까 통째로 읽지 말고 Node 명령으로 세어 줘(Python 은 쓰지 마). 어떻게 셌는지도 한 줄로 알려 줘.
확인

숫자 두 개와 「어떻게 셌는지」가 나온다. 이 숫자를 적어 둡니다 — 5단계에서 회사 기준으로 다시 세면 얼마나 달라지는지 봅니다.

무엇을 본 건가요과목수를 어떻게 세라고 말하지 않았으니 Claude 가 제 나름대로 셌습니다. 행을 셌을 수도, 학급을 셌을 수도 있습니다. 회사 기준은 Claude 가 스스로 알 수 없습니다 — 그래서 알려 줘야 합니다.
5

회사 기준을 알려 주고 다시 세기

방법
우리 회사 기준으로 다시 세 줘. - 공통: 프로그램명에 아래 말이 들어간 행은 뺀다 (과목이 아니다) 셔틀, 차량, 주도, 클리, 유형별, 실험복, 가방, 클린업, 무료 (부분 일치: 주도 = 자기주도 · 자주도, 클리 = 클리닉 · 클리커처럼 그 말이 들어간 것 모두) - 과목수: 학급수강상태가 수강인 행, 그리고 이수인 행 중 이동 열이 「이동-」(반이동)이 아닌 행만 센다. 요일 열이 「요일」이면 COLC + 요일 + 시작시간 + 종료시간, 월~일이면 COLC + 요일 + 시작시간 조합의 중복을 뺀 개수 - 학생수: 과목수와 같은 행(수강 + 반이동 아닌 이수)을 센터별로 학생코드 중복을 빼고 센 뒤, 센터 값을 더한다 (전체에서 한 번에 세지 않는다) 202609 의 과목수와 학생수를 알려 줘.
확인

두 숫자가 정답표.txt 의 202609 값과 같다(지금 쓰는 직영 대시보드와 같은 기준이라 대시보드 숫자와도 같다). 과목수가 4단계보다 크게 줄었다.

얼마나 달라지나요셔틀 · 클리닉처럼 과목이 아닌 것, 반을 옮기며 남은 이수 기록까지 과목으로 세어지고 있었습니다. 행 수에 비해 과목수가 약 5분의 1 줄어듭니다. 이 기준은 매번 다시 설명해야 하는 회사 규칙입니다 — 스킬로 묶기 딱 좋은 것입니다.
6

방금 정한 세는 법을 스킬로 만들기

방법
방금 정한 세는 법을 스킬로 만들어 줘. - 이 프로젝트의 .claude/skills/jig-metrics/SKILL.md 로 만든다 - name 은 jig-metrics - description 에는 무엇을 하는지 + 언제 쓰는지 + 내가 실제로 할 말(「학생수 세 줘」「과목수 알려줘」「몇 명 다녀?」「직영 인원」)을 한국어로 넣는다 - 본문에는 5단계에서 정한 기준 전부(제외 프로그램 9개 · 과목수의 수강/이수/반이동 조건과 요일 규칙 · 학생수 조건)와 「파일을 통째로 읽지 말고 Node 명령으로 센다(Python 은 쓰지 않는다)」를 넣는다

파일을 만들어도 되는지 물으면 Yes.

확인

왼쪽 탐색기에 .claude → skills → jig-metrics → SKILL.md 가 생긴다.

스킬 이름 규칙 (중요)공식 문서 기준으로 스킬의 name 은 최대 64자이고 영문 소문자 · 숫자 · 하이픈(-)만 쓸 수 있습니다. 한글 · 대문자 · 띄어쓰기 · 밑줄(_)은 안 됩니다. 예: jig-metrics (O) · 직영지표 · Jig_Metrics (X). 폴더 이름도 name 과 같게 둡니다.
5분 규칙5분 안에 안 되면 받은 정답_jig-metrics 폴더를 .claude\skills\ 안에 넣고 이름을 jig-metrics 로 바꾼 뒤 exit → claude.
7

구조 확인하고 /이름 으로 불러 보기

방법
  1. 폴더 모양이 skills/jig-metrics/SKILL.md 인지 봅니다. 파일 이름은 대문자 SKILL.md 여야 합니다.
  2. exit 로 끄고 claude 로 다시 켭니다. 켜 둔 창은 방금 만든 스킬을 아직 모르고, 다시 켜면 대화도 비워져 방금 알려 준 기준을 Claude 가 잊습니다.
  3. 입력창에 /skills → 목록에 jig-metrics 가 있는지 봅니다. Esc 로 닫습니다.
  4. /jig-metrics 202508 과목수와 학생수 → Enter
확인

기준을 다시 설명하지 않았는데도 정답표.txt 의 202508 값이 나온다.

다시 켜도 목록에 없으면1번 폴더 모양(.claude/skills/jig-metrics/SKILL.md)과 basic_data 폴더에서 켰는지를 다시 봅니다.
8

트리거 점검 · 수정

트리거 = SKILL.md 맨 위의 description 한 줄입니다. Claude 는 평소에 스킬 본문을 읽지 않고, 이름과 이 한 줄만 보고 「지금 이걸 쓸 때인가」를 고릅니다. 6단계에서 스킬을 만들 때 Claude 가 이 줄을 자동으로 써 두었습니다 — 여기서는 그 내용이 맞는지 보고 빠진 것을 채웁니다. 9단계에서 실제로 불려오는지 시험합니다.

방법

SKILL.md 를 열어 맨 위 --- 사이의 description 줄만 읽습니다. 세 가지가 들어 있는지 체크합니다.

들어 있어야 할 것예
무엇을 하나직영 데이터에서 과목수 · 학생수를 회사 기준(제외 프로그램 · 휴회 · 반이동 제외)으로 센다
언제 쓰나과목수 · 학생수 · 인원을 셀 때
내가 실제로 할 말「학생수 세 줘」「몇 명 다녀?」「과목수 알려줘」

빠진 게 있으면 말로 고칩니다: jig-metrics 스킬 description 에 ○○를 더해 줘

확인

트리거(description 한 줄)에 세 가지가 다 있다. 이름(name)은 64자 이하 · 영문 소문자 · 숫자 · 하이픈만이다 (6단계 이름 규칙).

안 되면 여기부터
  1. 안 불려온다 → jig-metrics 스킬은 언제 쓰는 거야? 라고 물어봅니다. Claude 가 description 을 읽고 답합니다. 답이 흐릿하면 그 답을 보고 description 에 「언제」와 「할 말」을 더합니다.
  2. 너무 자주 불려온다(ⓒ 에서도 뜬다) → description 끝에 「이럴 땐 쓰지 않는다: 인원 · 과목 수를 세는 일이 아닐 때」 한 줄을 더합니다.
  3. 그래도 안 된다 → 폴더 모양 .claude/skills/jig-metrics/SKILL.md 를 다시 보고, exit 후 다시 켭니다.

방법

방법
